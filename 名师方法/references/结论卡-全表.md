## 集合与常用逻辑用语

- **德摩根律**：∁ᵤ(A∩B) = ∁ᵤA ∪ ∁ᵤB；∁ᵤ(A∪B) = ∁ᵤA ∩ ∁ᵤB。
- **容斥原理**：card(A∪B) = card(A) + card(B) − card(A∩B)。
- **子集计数**：n 个元素的集合——子集 2ⁿ 个、非空子集 2ⁿ−1、真子集 2ⁿ−1、非空真子集 2ⁿ−2。
- **嵌套子集模型**：A 有 m 个元素、M 有 n 个元素（n≥m）——A⊆B⊆M 的 B 有 2ⁿ⁻ᵐ 个；改成"A⫋B"再减 1、"B⫋M"再减 1。

## 一元二次函数、方程和不等式

- **糖水不等式**：a>b>0、m>0 ⇒ b/a < (b+m)/(a+m) 且 (a+m)/(b+m) < a/b。
- **三角不等式**：||a|−|b|| ≤ |a+b| ≤ |a|+|b|；同型 |a−b|。
- **链式不等式**：√((a²+b²)/2) ≥ (a+b)/2 ≥ √(ab) ≥ 2/(1/a+1/b)（a,b>0，等号当且仅当 a=b）。
- **三元均值**：a³+b³+c³ ≥ 3abc（a,b,c≥0）；(a+b+c)/3 ≥ ∛(abc)。
- **柯西不等式**：(a²+b²)(c²+d²) ≥ (ac+bd)²（当且仅当 ad=bc）。
- **权方和不等式**：x,y>0 ⇒ a²/x + b²/y ≥ (a+b)²/(x+y)（当且仅当 a/x = b/y）。

## 函数

- **单调性**（定义式判断）：差商 (f(x₁)−f(x₂))/(x₁−x₂) > 0 增、< 0 减。
- **奇偶性**：f(−x)=f(x) 偶；f(−x)=−f(x) 奇（0 在定义域内则 f(0)=0）。
- **对称性**：f(a+x)=f(a−x) ⇒ 关于直线 x=a 轴对称；f(a+x)+f(a−x)=2b ⇒ 关于点 (a,b) 中心对称。
- **周期性五型**（a≠0）：① f(x+a)=f(x−a) ② f(x+a)=−f(x)+k ③ f(x+a)=k/f(x) ⇒ 三型 T=2|a|；④ f(x+a)=(1−f(x))/(1+f(x)) ⇒ T=2|a|；⑤ f(x+a)=(1+f(x))/(1−f(x)) ⇒ T=4|a|。
- **零点存在定理**：y=f(x) 在 [a,b] 连续且 f(a)·f(b)<0 ⇒ (a,b) 内至少一个零点。

## 三角函数

- **万能公式**：sinα = 2t/(1+t²)、cosα = (1−t²)/(1+t²)、tanα = 2t/(1−t²)，其中 t = tan(α/2)。
- **积化和差四式**：sinαcosβ = ½[sin(α+β)+sin(α−β)]；cosαsinβ = ½[sin(α+β)−sin(α−β)]；cosαcosβ = ½[cos(α+β)+cos(α−β)]；sinαsinβ = −½[cos(α+β)−cos(α−β)]。
- **和差化积四式**：sinA+sinB = 2sin((A+B)/2)cos((A−B)/2)；sinA−sinB = 2cos((A+B)/2)sin((A−B)/2)；cosA+cosB = 2cos((A+B)/2)cos((A−B)/2)；cosA−cosB = −2sin((A+B)/2)sin((A−B)/2)。
- **正弦平方差**：sin(α+β)·sin(α−β) = sin²α − sin²β。
- **余弦平方差**：cos(α+β)·cos(α−β) = cos²α − sin²β。

## 平面向量 · 解三角形

- **平行判定**：a=(x₁,y₁)、b=(x₂,y₂) ⇒ a∥b ⇔ x₁y₂−x₂y₁=0。
- **垂直判定**：a⊥b ⇔ x₁x₂+y₁y₂=0。
- **三点共线定理**：OA、OB 不共线 ⇒ A、B、C 共线 ⇔ 存在 x,y 使 OC = xOA+yOB 且 **x+y=1**。
- **"鸡爪"模型**：D 在 BC 上，BD:DC = m:n ⇒ **AD = n/(m+n)·AB + m/(m+n)·AC**。
- **极化恒等式**：D 为 BC 中点 ⇒ **AB·AC = |AD|² − |BD|²**。
- **定比分点公式**：AP = λPB ⇒ xₚ=(x₁+λx₂)/(1+λ)、yₚ=(y₁+λy₂)/(1+λ)。
- **投影向量**：b 在 a 上的投影向量 = |b|cosθ · a/|a| = (a·b/|a|²)·a。
- **重心**：① AG = ⅓(AB+AC) ② 重心坐标 = 三顶点坐标的平均 ③ 任意点 P：PG = ⅓(PA+PB+PC)。
- **正弦定理**：a/sinA = b/sinB = c/sinC = 2R；**余弦定理**：a²=b²+c²−2bc·cosA（及各轮换式）。
- **三角形外角平分线定理**：D 为 BC 延长线与 ∠A 外角平分线交点 ⇒ AB/AC = BD/CD。

## 复数

- |zⁿ|=|z|ⁿ；|z₁/z₂|=|z₁|/|z₂|（z₂≠0）；|z₁z₂|=|z₁||z₂|；|z|²=|z̄|²=z·z̄；**i⁴ⁿ⁻³+i⁴ⁿ⁻²+i⁴ⁿ⁻¹+i⁴ⁿ=0**。

## 立体几何与空间向量

- **斜二测**：S直视图 = (√2/4)·S原。
- **祖暅原理**：两平行平面间两几何体，任意同高度截面积相等 ⇒ 体积相等。
- **三垂线定理及逆定理**（线面垂直的连锁判定）。
- **面积投影定理**：二面角平面角 θ ⇒ |cosθ| = S投影/S。
- **三正弦定理**：AB 与 l 成角 θ₁、与平面 β 成角 θ₂ ⇒ sinθ = sinθ₁·sinθ₂。
- **空间向量基本定理**：三向量不共面 ⇒ 任意空间向量有唯一 (x,y,z) 表示。

## 直线和圆

- **相交弦定理**：PA·PB = PC·PD。
- **切割线定理**：PT² = PA·PB = PC·PD。
- **两圆的公共弦**：两圆方程相减即公共弦所在直线方程。
- **圆系方程**：过"直线与圆交点"的圆 = 圆方程 + λ·直线方程；过"两圆交点"的圆 = 圆₁ + λ·圆₂（λ≠−1）；λ=−1 时相减得公共弦/公切线方程。

## 圆锥曲线

- **中点弦（点差法）**：椭圆 x²/a²+y²/b²=1 上弦 AB 中点 M(x₀,y₀) ⇒ kOM·kAB = −b²/a²，中点弦方程 x₀x/a²+y₀y/b² = x₀²/a²+y₀²/b²；**双曲线**同型取 +b²/a²。
- **焦半径与焦点弦（角度式）**：椭圆 |AF₁|=b²/(a−c·cosα) 等四式，|AB|=2b²/(1−e²cos²α)；双曲线同型（分母换 ±）；**抛物线**（y²=2px）|AF|=p/(1−cosθ)、|AB|=2p/sin²θ。
- **通径**：α=90° 时 |AB| = 2b²/a（椭圆/双曲线）。
- **焦点三角形面积**：∠F₁PF₂=θ ⇒ 椭圆 S = b²·tan(θ/2)；双曲线 S = b²/tan(θ/2) = c·|y₀|。
- **阿波罗尼斯圆**：|PA|/|PB| = λ（λ>0 且 λ≠1）⇒ P 的轨迹是圆。

## 数列

- **等差数列六条**：① {aₙ} 等差 ⇔ {Sₙ/n} 等差（公差 d/2）② m+n=p+q ⇒ aₘ+aₙ=aₚ+a_q ③ **aₙ/bₙ = S₂ₙ₋₁/T₂ₙ₋₁**（两个等差列的对应项之比 = 各自前 2n−1 项和之比）④ Sₙ、S₂ₙ−Sₙ、S₃ₙ−S₂ₙ… 等差（公差 n²d）⑤ 共 2n 项 ⇒ S偶−S奇 = nd、S奇/S偶 = aₙ₊₁/aₙ ⑥ 共 2n−1 项 ⇒ S奇−S偶 = aₙ、S奇/S偶 = n/(n−1)（n≥2）。
- **等比数列四条**：① {1/aₙ}、{aₙ²}、{aₙaₙ₊₁}、{aₖ, aₖ₊ₘ, …}、{ln aₙ}（aₙ>0）各有对应等差/等比性；{aₙ+aₙ₊₁} 等比（q≠−1 时）② m+n=s+t ⇒ aₘaₙ=aₛaₜ，特别 **aₙ₋₁aₙ₊₁=aₙ²** ③ Sₙ、S₂ₙ−Sₙ、S₃ₙ−S₂ₙ… 等比（公比 qⁿ；q=−1 且 n 奇数例外）④ 前 n 项积 Tₙ ⇒ Tₙ、T₂ₙ/Tₙ、T₃ₙ/T₂ₙ… 等比（公比 q^{n²}）。
- **等比数列单调性**：a₁>0 时 q>1 增、0<q<1 减、q<0 交错；a₁<0 反之。**等比数列和的单调性**：a₁>0 且 q>0 ⇒ Sₙ 递增；a₁<0 递减；q<0 无单调性。

## 导数

- **定义**：f′(x) = lim(Δx→0) [f(x+Δx)−f(x)]/Δx。
- **极值判据**：x₀ 左增右减 ⇒ 极大值点；左减右增 ⇒ 极小值点。（**极值点是自变量的值，极值是函数值**）
- **高阶导数判极值**：f′(x₀)=0 且 f″(x₀)>0 ⇒ 极小值点；f″(x₀)<0 ⇒ 极大值点。
- **原函数与导函数的对称/周期关系**：① f 偶 ⇒ f′ 奇 ② f 奇 ⇒ f′ 偶 ③ f 关于直线 x=a 对称 ⇔ f′ 关于点 (a,0) 对称 ④ f 关于点 (a,b) 对称 ⇔ f′ 关于直线 x=a 对称 ⑤ f 周期 T ⇔ f′ 周期 T。

## 排列组合与二项式定理 / 概率统计

- **组合数**：Cₙᵐ = Aₙᵐ/m! = n!/(m!(n−m)!)。
- **二项式定理**：(a+b)ⁿ = Cₙ⁰aⁿ + Cₙ¹aⁿ⁻¹b + … + Cₙⁿbⁿ；**通项** T_{r+1} = Cₙʳaⁿ⁻ʳbʳ；系数和 Cₙ⁰+Cₙ¹+…+Cₙⁿ = 2ⁿ；**杨辉恒等式** Cₙ₊₁ᵐ = Cₙᵐ + Cₙᵐ⁻¹。
- **马尔科夫链**（两状态）：记第 n 次操作后处于状态 A 的概率为 Pₙ ⇒ **Pₙ = P(Xₙ=A|Xₙ₋₁=A)·Pₙ₋₁ + P(Xₙ=A|Xₙ₋₁=B)·(1−Pₙ₋₁)**——转移的线性递推模型。
