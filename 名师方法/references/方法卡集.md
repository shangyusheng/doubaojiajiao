## 卡 1 · 朱韬九阶（初中：计算怎么爬坡）

**什么时候走**：计算总错、练了不见好——但**说不出哪一步不行**。
**怎么走**：两道梯子各 9 阶；让孩子试"第 N 阶"的题，**能稳过就升阶、卡住就停在那阶补**（不从头刷）。

- **四则运算梯**：①有理数概念 ②加法 ③加法（带绝对值）④减法 ⑤减法（带绝对值）⑥加减混合 ⑦乘法 ⑧除法 ⑨乘除混合。
- **混合运算梯**：①简单四则混合 ②含乘方 ③多重括号 ④带绝对值 ⑤巧算·凑整 ⑥巧算·分组求和 ⑦巧算·连锁约分 ⑧巧算·裂项 ⑨巧算·错位相减。

**例题信号**：9 阶长这样——先给一段"示范"（S 乘公比再相减），再让学生仿做变式。
**出处**：朱韬《初中数学高频易错 500 题》七年级计算部分（18 份；每份自带难度星级 + 建议答题时长）。

## 卡 2 · 绝对值三板斧（初中）

**什么时候走**：绝对值化简 / 求值 / 方程发懵，分类总漏。
**怎么走**（一层层上）：
1. **概念斧**：正数本身、负数相反数、0 是 0——先能用一句话说清；
2. **分类讨论斧**：见 |…|+|…| 就**找零点分段**——让每个绝对值里为 0 的 x 值把数轴切开，一段一段去绝对值；
3. **几何意义斧**：|a−b| 就是数轴上两点距离；|x−a|+|x−b| 的最小值在 a、b 之间取到。

**例题信号**："已知 x 的范围化简""求 |x−1|+|x−3| 的最小值""含参绝对值讨论"。
**出处**：学而思《绝对值的化简求值（上/下）》（另有新版 docx 第 1/2 讲，内容同）。

## 卡 3 · 角平分线四招 + 中点两招（初中：几何辅助线）

**什么时候走**：题里有"角平分线""中点 / 中线"，但辅助线想不到。
**怎么走**（一条条往下试）：
- 见**角平分线**：① 向两边作垂线 ② 以角平分线为轴**反折**造全等 ③ 延长垂线段与另一边相交 → 出等腰（三线合一）④ 在两边**截取等线段**造全等；
- 见**中点 / 中线**：**倍长中线**（把中线延长一倍造全等）；要证"线段的和差"就**截长补短**。

**例题信号**：外角平分线比大小（PB+PC 与 AB+AC）、内心题（CA+AI=BC）、CD=2CE 型、BE+CF>EF 型。
**出处**：学而思《垂直平分线与角平分线（上/下）》《倍长中线与截长补短（上/下）》。

## 卡 4 · 变换三刀（初中：几何难题总开关）

**什么时候走**：图形"分散、不挨着"，或要证共线 / 最短路径。
**怎么走**：
- **平移**：把分散的线段"拼"到一处再比大小；
- **旋转**：等线段共顶点 → 转起来造全等；**半角模型**（正方形里 ∠EAF=45° ⇒ BE+DF=EF；等腰直角里 ∠MCN=45° ⇒ MN²=AM²+BN²）；等边三角形内一点 3-4-5 → 转 60°；**费马点**（∠AOB=∠BOC=∠COA=120°）；
- **轴对称**：**将军饮马** = 找对称点连直线（最短路径）；翻折造等腰 / 造全等。

**例题信号**：正方形绕中心旋转定值、四边+直角条件求面积、"角=2 倍角 ⇒ AB+BD=CD"。
**出处**：学而思《几何变换之平移 / 旋转 / 轴对称》三组。

## 卡 5 · 面积法三招（初中：证明利器）

**什么时候走**：证"距离和 = 定值"、平分面积、面积比类题。
**怎么走**：① **同底等高**（等积变形）② **割补** ③ **面积比 = 线段比**（共高）。
- 两条经典结论直接可用：**等腰三角形底边上任一点到两腰的距离和 = 腰上的高**；**正三角形内任一点到三边距离和 = 高**。

**例题信号**："过边上一点作直线把面积平分"、矩形内外点面积关系、内切圆半径 r = 2S/(a+b+c)。
**出处**：学而思《面积问题与面积方法（一/二/三）》。

## 卡 6 · 高中导数四套路

**什么时候走**：导数大题"没思路"或"证不出来"。
**怎么走**（对上题型走；**四个套路的"信号 / 步骤 / 坑"拆解见 `references\导数套路-深挖.md`**）：
- **同构**：两边凑成同一个函数再比较；
- **端点效应**：先看区间端点，必要性探路再证充分；
- **隐零点**（虚设零点）：设而代换，整体消掉；
- **双切线放缩**：找两条切线把曲线夹住。
（另有：对数均值不等式、用数列思想证导数。题型名全谱见 `references\题型-总表.md`。）

**例题信号**：恒成立求参、证明不等式、数列不等式。
**出处**：凉学长《创新拔高册》导数组。

## 卡 7 · 高中结论卡（精选；全表见 `references\结论卡-全表.md`）

**什么时候走**：小题要快、大题要减算。
**怎么走**：**报结论 + 说一句"为什么成立"**（不许只报结论）。
- **不等式**：糖水不等式 b/a < (b+m)/(a+m)；柯西 (a²+b²)(c²+d²) ≥ (ac+bd)²；权方和 a²/x + b²/y ≥ (a+b)²/(x+y)；
- **函数**：f(a+x)=f(a−x) ⇔ 关于直线 x=a 对称；f(a+x)+f(a−x)=2b ⇔ 关于点 (a,b) 对称；周期四型；
- **三角**：积化和差 / 和差化积 / 平方差公式；
- **数列**：等差 6 条、等比 4 条（清单见 `references\结论卡-全表.md`）；
- **导数**：原函数与导函数"奇偶互推、周期同周期、对称互推"；f′(x₀)=0 且 f″(x₀)>0 ⇒ 极小；
- **概率**：**马尔科夫链**（两状态线性递推）。

**出处**：赵礼显《高考数学必会 1500 题》"重要定理 + 二级结论"页（整理版见 `references\结论卡-全表.md`）。
⚠️ **张角定理别引用**（整理时没抄全，全表里也没收）。

## 卡 8 · 圆锥曲线 / 数列"减算"清单

**什么时候走**：圆锥曲线算到一半算崩；数列求和卡。
**怎么走**：
- **圆锥曲线**：**点差法**（中点弦 kOM·kAB = −b²/a²，双曲线取 +）、**硬解定理**、**非对称韦达**、焦点三角形面积 b²·tan(θ/2)、焦半径角度式；
- **数列**：**裂项相消**、**错位相减**、**特征根**（递推转等比）。

**出处**：凉学长题型总表（名谱见 `references\题型-总表.md`）；**做法不在本卡的就按通用讲法走**。
