## 同构（指对同构）

**信号**：式子里**同时出现 eˣ 与 ln x**——恒成立、方程根的个数、比大小都算。

**步骤**：

1. **恒等变形、拆组重配**：常用 x = e^{ln x} 互化，把常数也写成 e^{…}，把等号 / 不等号**两侧凑成同一个函数的两边** f(u) ≥ f(v)。
2. **认母函数**：常用 **f(t) = eᵗ + t**（也见 f(t) = t·eᵗ 一类）。
3. **脱外套**：母函数单调递增 → f(u) ≥ f(v) ⇔ **u ≥ v**，把函数去掉。
4. 剩下的就是普通不等式 / 交点个数问题，求导解决。

**坑**：凑不出"同一个函数"就是凑错了（回头改配法）；母函数的单调性要交代一句；对数域（x>0）别丢。

**例题信号**：

- `ae^{2x} ≥ ln(x/a)` 型恒成立求参——配成 e^{ln a+2x}+(ln a+2x) ≥ e^{ln x}+ln x，得 ln a+2x ≥ ln x。
- `a = −x ln x` 的交点个数型——两边配成 e^{a/x}+a/x = e^{ln(1/x)}+ln(1/x)。
- 比大小：先两边取对数，凑成同一函数再用单调性比。

**出处**：赵礼显《高考数学必会 1500 题》第 11 章 模块五 题型 3「同构问题」（解析 D502，含"指对同构思想"方法句与 f(t)=eᵗ+t）；凉学长《创新拔高册》题型二「同构」（p23-25）。

## 端点效应

**信号**：含参、**单侧区间**上的恒成立（f(x) ≥ 0 在 [a,+∞) 之类），而且**区间端点处 f 恰好为 0**——那是命题人给的"端点"。

**步骤**：

1. **先算端点值**（如 f(1)=0）。
2. **必要性**：由**端点处的导数符号**给出参数的必要范围——f′(1) ≥ 0 ⇒ a ≥ −1（"端点效应"就在这一步）。
3. **充分性**：把必要范围**代回**，求导 + 单调性证明该范围内恒成立。
4. 备选：分离参数 / 半分参（导数分子麻烦时）。

**坑**：**做出必要条件就收笔是最大的坑**——必须补充分性证明；端点处导数恰为 0 的边界要代回看一眼；最终答案写范围（不是点值）。

**例题信号**：

- `x²−x+a ln x ≥ 0` 在 `[1,+∞)` 恒成立求 a 范围——f(1)=0 → f′(1)≥0 → a≥−1 → 代回证。
- 「f(x) > −2 **当且仅当** 1<x<2」求参——两端都是界。

**出处**：赵礼显《1500 题》第 11 章 模块八 恒成立与能成立问题（题 6，解析 D518 含"方法点拨"）；凉学长《创新拔高册》题型五「端点效应」（p28-29，含 2024 新高考一卷真题）。

## 隐零点（虚设零点）

**信号**：恒成立 / 最值 / 零点证明题；求导后 `f′(x)=0` 是超越方程**解不出来**（式子里挂着 ln x、eˣ），但 f′ 单调（二阶导定号，或显然看出来）。

**四步**：

1. **先证"存在且唯一"**：证 f′ 单调 + 两端异号（x→0⁺、x→+∞ 的符号）→ 存在唯一 x₀ 使 f′(x₀)=0。
   要整数答案时，再用零点存在定理把 x₀ **夹进相邻整数之间**（如 h(3)<0、h(4)>0 ⇒ x₀∈(3,4)）。
2. **写"钥匙式"**：把 f′(x₀)=0 整理成能代换的样子——常见两种写法：
   - 把**参数**提出来（如 2a = x₀(ln x₀ + 1)）；
   - 把**超越项**换成多项式（如 ln x₀ = x₀ − 2）。
3. **整体代换**：拿钥匙式把 f(x₀)（或目标式）里的参数 / ln、eˣ **整体消掉**——剩下的只含 x₀
   （例：分式化到 x₀+1；f(x₀) 化到 x₀(ln x₀)²）。
4. **对 x₀ 求界**：用第 1 步夹出的范围直接定界（整数题到此结束）；要精确最值时，对 x₀ 再构造一个函数求导。

**坑**：

- 设 x₀ 之前必须先把"存在且唯一"证掉——直接说"设零点 x₀"是丢分点。
- 钥匙式的方向选"**能消掉最碍事那项**"的写法；选错了代换不干净。
- x₀ 的范围要卡准——整数题（求 k 最大整数）全靠它。
- 设完别回头"解 x₀"——它本来就解不出来。

**例题信号**：

- 含 ln x 的恒成立、**求 k 最大整数**（如 `x(ln x−1/x+2)>k(x−1)`）——x₀ 夹在 (3,4)，靠 x₀+1 的范围定 k。
- 含参恒成立、**求"参数组合"的最小值**（如 `f(x)=(2a−x)ln x` 求 `b−5a`）——把 2a 用钥匙式 `x₀(ln x₀+1)` 换掉。
- `(x−k)f′(x)+x+1>0` 型——乘开再虚设零点。

**出处**：赵礼显《高考数学必会 1500 题》第 11 章 模块七 题型 1「隐零点的虚设与代换」（书 p247，解析 D509–D511）；凉学长《重点必考册》题型十「虚设零点/隐零点」（书 p52）。

## 双切线放缩

**信号**：题面挂着"切线"——证明**曲线在切线某一侧**；或**两个函数值相等的点 x₁、x₂** 要证 x₁+x₂ / x₁x₂ 的范围；以及比大小、恒成立里要把 eˣ、ln x **换成一次式做界**的。

**基本件（先会这个）——切线放缩三条，记住等号点**：

- **eˣ ≥ x+1**（等号在 x=0）；
- **ln x ≤ x−1**（等号在 x=1）；
- **ln(1+x) ≤ x**（x>0，等号在 x=0；比大小常用）。

用法：把超越函数换成一次式，恒成立 / 最值就能直接算。

**"双"的部分（材料缺口，照实说）**：两条切线怎么分工（哪条当上界、哪条当下界、切点怎么选）——**现有材料只有题、没有文字解法**（凉学长两册的讲解在视频里）。遇到这类题：先用上面的基本件试；确需两条切线时，按"在两个点上各取一条切线、把曲线夹住"这句办——**这句是从题型名和例题结构来的，没核过原解法**，跟孩子说"这类题我们试一种路子"就好。

**例题信号**：

- 求切线 → 证"曲线在切线下方" → 两等值点证 x₁+x₂ 的界（合肥二模型）。
- 切点固定在 x=−1、求参后"方程有两实数根 x₁<x₂"型。
- 比大小用 ln(1+x) ≤ x 压界；恒成立用 eˣ ≥ x+1 换参。

**出处**：题——凉学长《创新拔高册》题型十（p38-39）、千题册创新拔高（上）题型七（p80-82）；基本件——赵礼显《1500 题》（对数切线放缩，解析 D499；eˣ ≥ x+1 求参，解析 D538）。
