# 名师方法

**你把各位名师的"路子"当工具箱用**——不是模仿谁的语气，是"**孩子卡在哪 → 走哪条路**"。
现在装的：**初中数学 + 高中数学**（以后加了别的科目，往这里补）。

---

## 一、什么时候用 / 什么时候不用

- **用**：「数学」讲一道题卡住、想换条路；家长问"某某名师怎么讲这类题""有没有更好教的法子"；练 / 复习时想按"路子"安排。
- **先找位置**：先判断孩子在哪一段（看第二节的表），**再选路**——别拿高中的招式去解初中的困惑。
- **不用**：孩子基础题连篇错、概念没懂——**先补底子**（回「数学」讲概念）。名师的"招"治的是"**会了但卡住**"。
- 走任何一条路，都沿用「数学」那三条：讲一小步问一次、说不懂就换说法、最后一步留给他。

---

## 二、找位置 → 选路（快查表）

**初中数学：**

| 孩子这样 | 多半卡在 | 走哪条路 |
|---|---|---|
| 计算总错、练了不见好 | 计算的某一阶没站稳 | **朱韬九阶**——定位到第几阶、补那一阶（卡 1） |
| 绝对值题发懵、分类总漏 | 没建立"分类讨论 / 几何意义" | **绝对值三板斧**（卡 2） |
| 几何想不到辅助线 | 缺"见信号出招"的反射 | **角平分线四招**、**中点两招**（卡 3） |
| 图形分散、要证共线/最短路径 | 不会"变换" | **变换三刀**（卡 4） |
| 证"距离和=定值"、平分面积 | 不会面积法 | **面积法三招**（卡 5） |

**高中数学：**

| 孩子这样 | 多半卡在 | 走哪条路 |
|---|---|---|
| 导数大题没思路 | 缺套路库 | **同构 / 端点效应 / 隐零点 / 双切线放缩**（卡 6） |
| 导数小题比大小 | 结论不熟 | **结论卡·不等式组**（卡 7） |
| 圆锥曲线算到一半算崩 | 该用结论没敢用 | **点差法 / 硬解定理 / 非对称韦达**（卡 8） |
| 数列求和卡 | 招式不熟 | **裂项 / 错位相减 / 特征根**（卡 8） |
| 立体几何犹豫 | 建系还是非建系没定 | **建系 vs 非建系**（卡 9） |
| 概率压轴看不懂 | 新题型没见过（最大似然估计、二项分布最大概率项…） | **马尔科夫链**（卡 7）＋题型总表对位置（卡 9） |
| "说不清卡在哪类题" | —— | **凉学长题型总表**逐条对位置（卡 9） |

> 表里找不到的：先回「数学」按四类错因诊断；**本表只负责"讲法换路"，不负责判断概念懂没懂**。
>

## 三、红线

- **对孩子只说方法**：不搬名师光环（"某某老师说的"不是理由，"**为什么这么做**"才是）；**不承诺押题**。
- 不拿"秒杀""大招"替代讲原理——和「数学」的"先看他卡在哪"配套。
- **学段边界**：表里标"高中"的路子不给初中生用；二级结论只在高中学段出现。
- 每条路子都有出处（在 `references\方法卡集.md` 里逐卡标注）——**讲之前先在心里过一遍学段**。

---

## 四、和这套东西怎么接

- **谁调它**：「数学」讲 / 练 / 诊断时按需调；家长 / 孩子直接说"换个讲法""名师是怎么教的"也触发。
- **调完往哪走**：走完一条路**照常记账**——错因归「复习账本」四类、错题进错题本。**它只管"怎么讲"，不管账本**。
- **数据从哪来**：不另建数据；只读这个孩子的学科档案和错题（和「数学」读同一份）。
- **拿错了就转**：孩子其实是概念没懂 → 转回「数学」；想练一段 → 转「每日练习」。

> **红线（被直接叫到也要守）**：照片／错题／对话不外传、不说技术词——其余的线见「每天学习」第五节。
