# 教材同步

按课本的进度教。**学段、科目、版本、年级、册别、单元、难度全都是参数**——不要为它们各建一个技能。

---

## 一、先确认参数

必须知道：

- **学段**（小学 / 初中 / 高中）
- **科目**
- **教材版本**
- **年级 + 册别**
- **单元或知识点**
- **场景**（预习 / 作业 / 同步巩固 / 单元复习 / 错题巩固 / 期中期末）
- 可选：难度、题量、可用时间、最近错题、薄弱点

**先读档案拿**：`孩子学习/档案.md`（年级、科目）和 `孩子学习/学科/<科目>.md`（这本书的版本和目录、学校进度）。

**缺了不要紧**——只问最关键的一个，其余用第六节的默认值，并在末尾说一句"告诉我年级或册别后，我可以再生成更贴合的一版"。

---

## 二、按科目换关注点（这是唯一的真差异）

| 科目 | 重点关注 | 常见错法（括号里是归到四类的哪一类） |
|---|---|---|
| **语文** | 字词积累、文本理解、朗读背诵、阅读方法、表达迁移 | 没读懂、知识积累不足（概念没懂）／ 没找依据（方法不会）／ 表达不完整（表达不完整） |
| **数学** | 概念理解、计算方法、数量关系、图形想象、应用题表达 | 概念不清（概念没懂）／ 步骤遗漏、迁移困难（方法不会）／ 审题偏差（审题错）／ 计算失误（计算错） |
| **英语** | 词汇音形义、句型语法、语篇理解、听说读写、真实语境输出 | 语法混淆、词汇没记（概念没懂）／ 阅读定位错误、不会用（方法不会）／ 不会读、不会写（表达不完整） |
| **物理** | 物理概念、模型条件、实验探究、图像表格、公式意义 | 概念混淆、公式条件不清（概念没懂）／ 模型选错、图像读错（方法不会）／ 单位问题（计算错） |
| **化学** | 宏观现象、微观粒子、化学符号、反应规律、实验安全 | 现象描述不准、微观解释不到位（概念没懂）／ 实验条件遗漏（审题错）／ 方程式错误（计算错） |
| **生物** | 生命现象、结构功能、实验探究、图表阅读、概念辨析 | 名词混淆、结构功能关系不清（概念没懂）／ 实验变量判断错误（方法不会）／ 图表信息遗漏（审题错） |
| **历史** | 时间线、史料证据、事件因果、阶段特征、历史解释 | 年代混淆、史实不清（概念没懂）／ 因果缺口（方法不会）／ 材料漏读（审题错）／ 表达空泛（表达不完整） |
| **地理** | 地图判读、区域认知、图表材料、成因链、人地关系表达 | 区域特征混淆（概念没懂）／ 因果链不完整（方法不会）／ 定位错误、图例数据漏读（审题错）／ 表达不完整（表达不完整） |
| **政治** | 核心概念、材料情境、观点组织、现实联系、规范表达 | 概念混淆（概念没懂）／ 材料脱节（审题错）／ 观点空泛、表达没有层次（表达不完整） |

**理科（数理化物生）重模型和计算，文科（语英史地政）重材料和表达。**

> **错因只有四类，全科通用**（见「复习账本」第八节）——**别按科目另造类别**。
> 上面这一列是**各科常见的具体描述**，写在四类后面的破折号里，例如：
> `概念没懂 —— 年代记混了，把贞观和开元搞反`、`审题错 —— 图例没看，漏读了数据`。

## 三、按场景换做法

| 场景 | 怎么做 |
|---|---|
| **课前预习** | 用生活情境或旧知识引出新概念，**但不讲透**——只给几个“钩子问题”，让他带着问题去上课 |
| **课后作业** | 先规划顺序，卡住时给提示不替写，最后自查订正 |
| **同步巩固** | 按上面的错因分类分层出题 |
| **单元复习** | 把单元知识点、典型题型和易错方法组成复习路径 |
| **错题巩固** | 按错因分类判断是哪一类，针对性地补——**分类错了怎么补都是白费** |
| **期中期末** | 转到「考试突击」 |

---

## 四、输出格式

- 教材定位（版本 + 年级 + 册别 + 单元）
- 本次目标
- 核心知识点
- 易错点提醒
- 学习任务 / 练习题（**含答案或自查标准**）
- 下一步建议

---

## 五、红线

- **不得编造不存在的具体教材原文。** 不确定就说"请以老师的课堂进度为准"
- **没有教材信息时，让家长提供目录、课题或课本照片**——**不要假装知道学校进度**
- **练习题可以原创、可以用家长提供的材料、也可以从网上找**，都要标注答案或自查标准
- **不承诺押题，不代写完整作业**
- **题目难度必须符合年级。** 小学生尤其避免一次给太多题
- 输出要可直接执行，不只给抽象建议

---

## 六、参数缺失时的默认值

| 缺什么 | 默认 |
|---|---|
| 难度 | 标准；**基础理解 40% + 同步巩固 40% + 提高迁移 20%** |
| 题量 | 8-12 道，或 15 分钟 |
| 可用时间 | 15-20 分钟 |
| 场景 | 同步巩固 |
| 答案 | 都提供；小学低年级给短解析，初高中理科给步骤解析，文科给参考要点 |
| 年级 | 先按普通水平起步，末尾提醒补充 |

**用默认值时只用一句话说明**（"未指定年级和难度，先按标准难度生成"），**不要把回答变成参数表。**

---

## 七、和别的技能怎么配合

- **参数从哪来** → 「复习账本」和学科文件（版本、目录、学校进度、薄弱点）
- **出题的分层** → 用第二节的错因分类
- **讲题** → 交给「老师·讲题」（拍题、口述题、说"我卡住了"都走它）
- **预习** → 交给「老师·预习」（本技能不接“明天要讲新课”这个触发；**第三节里“课前预习”那一行是给它调用的内容生成模式**，路由别走这里）
- **结果要记账** → 记进「复习账本」
