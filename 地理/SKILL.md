## 二、地理的错分四种

| 类别 | 孩子会怎么说 | 怎么补 |
|---|---|---|
| **概念没懂** | "记混了""不知道这是啥" | 回去讲概念——**把知识挂到图上** |
| **方法不会** | "知道要干什么，但说不清为什么" | 讲方法 + 练同类（图） |
| **审题错** | "看漏了""图例没看清" | 练读图读题（先圈图名、图例） |
| **表达不完整** | "我会做，就是写不出来" | 练说、练写（分点 + 术语） |

**地理最容易混的两个**：

- **"没记住"和"没读懂"是两回事** —— 让他**复述题和图**，就知道是哪一种
- **"不会做"和"表达丢分"是两回事** —— 思路对但写不出来 = 表达问题，练说练写，**不是再刷题**

## 三、地理怎么讲

> **展开版在 `references\讲-方法与话术.md`**：讲一道题的完整流程（每一步问什么）、
> "换个说法"的具体换法、读图和等高线的招数、初高中各自的坎、带图的题怎么办（兜底句）。
> **这里有的，那里不重复。**

### 共同的三条（不分学段）

1. **先给他选项**（照第二节四类），别让他自己想说
2. **讲一小步就问"这一步懂了吗"**（懂了 / 有点糊 / 还是不懂）——**"有点糊"那一档必须留着**
3. **说"不懂"就换个说法**（不许重复原话）；**最后一步（说出结论）留给他**

### 地理讲一道题的骨架：看图 → 定位 → 成因 → 表达

1. **看图**：先让他说图上有什么——**先别替他说**（这也是在看他卡在哪）
2. **定位**：这是哪？按架子说位置：**半球 → 纬度带 → 海陆位置 → 相邻**
3. **成因**：由果溯因，**自然 + 人文两列**，**主导因素先讲**，讲一步问一步
4. **表达**：用自己的话说一遍，再换术语（"雨很多"→"降水丰富、集中"）

**"换个说法"往哪换**（他卡住就一条条试；括号里是例子）：

| 招 | 怎么用 |
|---|---|
| **换尺度** | 大的讲不懂就放小（世界 → 中国 → 家乡） |
| **换要素** | 气候讲不通，从地形切（气地水土生，挑一个进） |
| **换维度** | 自然讲不通换人文（人对地做了什么） |
| **换载体** | 说不出来就画（简图 / 箭头）；图看不懂就回到文字 |
| **换参照** | 拿他熟悉的同类区域比（"跟你老家比呢？"） |

> **能说出来才算真会**：讲完让他**用自己的话说一遍**。
> 说不清的地方就是没懂的地方——比再讲一遍有用。

### 初中：两个坎

- **坎①空间转换**：等高线是"把立体的山压平到纸上"——先用实物 / 手比一次，再回图
- **坎②规则套用**：经纬网、半球、五带——先把规则背顺，再练套用

### 高中：先"判题型"，再动手

- **先判题型**：特征描述 / 成因分析 / 影响评价 / 措施对策——**判错题型 = 白写**
- **成因 = 两列**：自然（气地水土生）+ 人文（人口 / 市场 / 交通 / 政策…）
- **答题五步**：审题干（圈关键词）→ 列角度 → 用材料筛 → 组织语言 → 分点写

## 四、地理怎么练

> **展开版在 `references\练-方法与配比.md`**：地理特色的练法（换图复测 / 填图 / 看图说话）、
> 初中和高中各自多出来的一条、几条例子。**这里有的，那里不重复。**

### 共同（不分学段）

- 讲完一道题 → 同类**变式 1-2 道**（**换图、换区域、换问法**，**不是原题**）
- **同类错点换一张新图复测**（防"记住的是那张图"）
- 反馈**必须标错因**，不能只说对错（例：不说"错了"，说"这题错在**审题**——图例没看，把铁路看成公路了"）
- **一次只练一个小目标**：一张图、一个考点

#### 难度：三档，配比按孩子调

| 档 | 是什么 | 干嘛用 |
|---|---|---|
| **基础** | 他会的 | 热身、稳住基本分 |
| **巩固** | **刚好不会那条线** | **出题主力**——找的就是这条线 |
| **拔高** | 够一够能到的 | 往上顶 |

配比默认 **40% / 40% / 20%**（中等水平）：基础薄弱 → 基础多、**拔高几乎没有**；好学生 → 巩固拔高多、基础只热身。

**拔高的方向**：同一个考点往深走——**加图**（单图 → 组合图）、**加环**（读图 → 加成因 → 加影响）、**换陌生区域**。

> **不往上学段。** 初中的孩子给高考题——他缺的是**工具**，不是智力，只会看不懂而挫败。

> ⚠️ **别把三个"档"混起来——名字像，管的事完全不同**（难度三档就是这一节；
> 五档降级和三档判定在「复习账本」第九节、第二节）。

### 初中

- **填图 / 看图说话**：手边纸上画个轮廓、标地名——把知识**挂到图上**；挑一张图让他口头描述

### 高中

- **四类题型专项**（特征 / 成因 / 评价 / 措施）+ **限时练** + **术语替换**（每天把 3 句大白话改成地理说法）

## 五、地理怎么诊断（摸底和考试看什么）

> **展开版在 `references\诊断-错因与诊断卡.md`**：四类错因在地理里的具体表现、
> **14 张诊断卡**（初中 7 / 高中 7，按知识点查：常见错法 → 卡点 → 补救讲法 → 变式提问）、
> 各学段知识树骨架、**超纲红线**。

| 学段 | 看什么 |
|---|---|
| **初中** | 定位准不准、图例读没读、成因能不能说出来 |
| **高中** | 题型判断、成因两列全不全、术语表达 |

**反馈时多看两点**（**不算新的错因类别**——记账、给孩子认，永远只有四类）：
**读图依据**（答案说得出从图上哪来的吗）和**因果链完整**（因 → 果说全了吗）。

**孩子拿来一道题、或者一道题反复错** → 翻 references 里的诊断卡，对号入座。

**摸底的做法见「摸底」**：一科 6-8 题、**一次只给一道**、从"这一年的中等难度"起步、对加难错降。
