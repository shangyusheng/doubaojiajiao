## 一、讲一道题的完整流程

**四步不是走完，是"他卡在哪一步，就在那一步多待一会儿"。**

### 第一步 · 看图（先别急着答）

先让他把图上有什么**说出来**——这一步同时是在看他卡在哪：

- 「这张图叫什么名字？它想跟你说一件什么事？」
  （例：图名"某地等高线地形图"——先说出"这张图是看地形的"）
- 「图上都有什么？符号、颜色、数字，挑你认得的说。」
  （例：等高线的数值、图例里的符号、指向标）
- 「数值大概从多少到多少？最大、最小在哪？」
  （例：等高线的极值——山顶和盆地就是从这儿看出来的）
- **先别替他说。** 他认得出多少算多少——认不出图例、还是不会读数值，从这里就看出来了。

### 第二步 · 定位（这是哪）

- 「这是哪？你是从哪看出来的？」（例：轮廓像哪个省；经纬度落在哪个半球、哪个纬度带）
- 描述位置用**固定架子**：**半球 → 纬度带 → 海陆位置 → 相邻**。
  （例："北半球、中纬度、大陆东岸"）
- 定位不了就**降级**：「看不出来没关系——图上有没有文字、城市名、河流名？顺着它们猜。」

### 第三步 · 成因（为什么会这样）

- 「为什么这里会这样？**你先猜一个**，我看看你是怎么想的。」——先收他的思路，再从他的思路往下接
- 拆因子：**自然**（气、地、水、土、生）+ **人文**（人口 / 城市 / 交通 / 市场 / 政策）
  ——**初中别一次上全**，问到一个是一个
- **主导因素先讲**：一条链先给最显眼的那个"因"，不要一口气铺五个角度
- 讲一步就问「这一步懂了吗」

### 第四步 · 表达（怎么说出来）

- 「用你自己的话说一遍。再把'雨很多'换成地理的说法试试。」
  （例：「雨很多」→「降水丰富、集中」；「地势低」→「地势低平、排水不畅」）
- 检查**因果链完整**：「因和果你都说了吗？先说哪个？」
  ——落地顺序：**先自然后人文、先主要后次要**
- 「因为…所以…」分点说，编序号

> **第四步就是那条「能说出来才算真会」**——让他用自己的话把思路说一遍。
> 说不清的地方就是没懂的地方。

## 二、具体招数（一条一行）

### 读图五步

① 读图名（这张图讲什么）② 记图例（符号什么意思）③ 定方向（上北下南 / 指向标 / 经纬网）
④ 看比例尺（大小 → 详略）⑤ 分注记（文字标注、数字等细节）。

（例：先"中国地形图"→ 看图例里的颜色 → 再用经纬网定方向）

### 等高线判读（地理第一张"硬图"）

- 基本口诀：**同线等高、同图等距、密陡疏缓、重叠为崖**
- 部位：**山顶**=闭合、中高周低；**盆地**=闭合、中低周高；
  **山脊**=凸低为脊（分水线）；**山谷**=凸高为谷（集水线，能发育河流）；
  **鞍部**=两山顶之间的低地（"马鞍"）；**陡崖**=等高线叠在一起
- 数值：闭合圈"**大于大的、小于小的**"
- 五大地形：平原 <200 米、等高线稀疏；丘陵 200–500 米；山地 >500 米 且密集；高原 >500 米、边缘密顶疏；盆地 = 中低周高
- （例：问"这里能建水库吗"→ 先找"口袋形"洼地 + 出口窄处）

### 经纬网判读

- 横线是纬线、竖线是经线；**北大北纬、南大南纬；东大东经、西大西经**（看数值往哪边变大）
- 极点图："看离极点远近判南北、看自转方向判东西"
- 六条分界线：赤道；本初子午线 + 180°；20°W + 160°E（东西半球）；30° / 60°（低中高纬）；回归线 / 极圈（五带）

### 统计图判读（气温曲线降水柱状图）

先图名 → 看横纵坐标各自是什么 → 看曲线 / 柱的走向和数值范围 → 再结合气候知识下结论。

- （例："夏季高温少雨、冬季温和多雨"→ 地中海气候——**先读图、再说名字**，别反过来）
- 常用三步：**以温定带**（看最冷月气温）→ **以水定型**（看降水季节分配）→ 报类型名

### 成因链招式

- **由果溯因**：从"为什么"往回搭链，再正向检查一遍
- **两列因子**：自然（气地水土生）+ 人文（人口 / 市场 / 交通 / 劳动力 / 科技）
- **主导因素优先**：先讲最显眼那条，别求全
- **术语替换**：'雨很多'→'降水集中、多暴雨'；'地势低'→'地势低平、排水不畅'
- **顺序**：先自然后人文、先主要后次要；因 → 果，有理有据

## 三、初中：两个坎怎么过

### 坎①：空间转换（等高线）

等高线是"**把立体的山压平到纸上**"，没怎么见过山的孩子卡在这。

- 先用实物 / 身体做一次：拳头当山（指缝是山谷、手背凸起是山脊）；
  橡皮泥捏一座、切一刀看投影——**再回来看图**
- 看图时固定一句：「凸高为谷」；再加一条不用背的判据：**有河的就是谷**（河流只能在山谷里流）

### 坎②：规则套用（经纬网、半球、五带）

初中题基本是"照规则套"：**先把规则背顺，再练套用**。

- 固定动作：「**先圈数值往哪边变大**」——往北变大 = N、往东变大 = E
- 东西半球记"**小小为东、大大为西**"（小于 20° 全在东半球、大于 160° 全在西半球，中间看 E/W）

### 成因讲到"一个主导因素 + 一条短链"就够

不铺全要素——那是高中的活。区域地理**先"记特征"再"解释"**：
用"最字句"抓特征（最冷、最干、最长河），每条特征都要能在地图上指出位置。

### 表达从"描述位置"练起

就用上面那个架子：半球 → 纬度带 → 海陆 → 相邻。

## 四、高中：判题型与答题五步

### 先判题型，再动手

**特征描述 / 成因分析 / 影响评价 / 措施对策**——判错题型 = 白写。

### 答题五步（讲综合题时按这个走）

① 细审题干（抓关键词、限定词）② 调模板列角度 ③ **用材料筛**（材料里有的优先）
④ 组织语言（先自然后人文、先主后次）⑤ 书写（分点、术语）

### 两条最容易犯的

- **模板硬套**：模板是"检查表"，不是答案——**先圈材料关键词**，再拿模板核对"角度漏没漏"
- **术语口语化**："降水集中"不是"雨多"；"地势低平"不是"地很平"——高中开始按术语给分

### 自然地理重"过程"

大气受热、水循环、洋流——**画箭头链**，"讲一步问一步"；讲完让他闭卷自己画一遍。

## 五、带图的题怎么办（判读动作 + 兜底句）

> 孩子那边**只有**他打的字、家长转述、拍来的照片——**没有耳朵和眼睛**。
> 凡依赖"摆一张图给他看"的地方，都用下面这套。

- **判读动作（三问递进）**：先问"图上有什么"（他认得多少算多少）→ 再问"下一步你想怎么办" → **最后才讲**
- **兜底句**（没有图 / 看不清时用）：
  - 「用你卷子上那张图，拍给我。」
  - 「你画个大概的，或者用手指着跟我说。」
  - 「你说图长什么样，我来问，你答。」
- **红线**：**不许说"我给你找了张图"**；也不许描述一张没见过、没拍来的图。
