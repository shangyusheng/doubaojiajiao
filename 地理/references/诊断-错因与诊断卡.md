## 一、四类错因，在地理里长什么样

> 「复习账本」第八节给的是四类的机制，这里只说**地理里的具体表现**。

- **概念没懂** —— "记混了 / 不知道这是啥"。地理的概念断层。
  （例：把亚洲和欧洲的地形记反；"天气"和"气候"混、"地形"和"地势"混）
  **补法 = 回去讲概念 + 把知识挂到图上。**
- **方法不会** —— "知道要干什么，但说不清为什么"。因果链接不下去、判断依据说不出来。
  （例：只会说"因为热"，接不出下一环；答案对但说不出为什么对）
  **补法 = 讲方法 + 练同类（图）。**
- **审题错** —— "看漏了 / 图例没看清"。地理特有的几种：
  **定位错误、图例数据漏读**、漏看限定词（"从地形角度"只看了一半）。
  **补法 = 练读图读题**（先圈图名和图例、圈限定词）。
- **表达不完整** —— "我会做，就是写不出来"（地理归**文科**这一类）。
  写一两句就完、不用术语、不分点。
  **补法 = 分点 + 术语替换**（见「讲-方法与话术」第四节、「练-方法与配比」第三节）。

> 这里面最容易混的两对——"没记住"和"没读懂"、"不会做"和"表达丢分"——
> **判法在 `SKILL.md` 第二节**，这里不重复。

## 二、诊断卡（按知识点查）

> 每张卡：**常见错法 → 背后卡点 → 补救讲法 → 变式提问**。
> 用法：孩子拿来的题对上了哪张，就按它的"补救讲法"走，再用"变式提问"验他是不是真懂了。
> 一道题**反复错**的时候也翻这里——多半能对上某一张。

### 初中

**等高线：山脊 / 山谷判反**
- 常见错法：把山谷看成山脊（凸向判反）；不知道哪条线可能有河
- 背后卡点：口诀背反了（记成"凸高为脊"）；没和"河流只走山谷"挂钩
- 补救讲法：两句话锁死——"**凸高为谷**"；再给一条不用背的判据：**有河的就是谷**。
  拿手比一次（指缝是谷、手背凸起是脊），再回图上对
- 变式提问："图上哪里最可能有小溪？"→ 换成"想爬山省力走哪边？"（看疏密）

**经纬度：N/S、E/W 写反 / 东西半球判错**
- 常见错法：把北纬写成"S"；东西半球按 0°/180° 分（忘了 20°W/160°E）
- 背后卡点：规则背了但没成动作——看到图不先看"数值往哪边变大"
- 补救讲法：固定一个动作"**先圈数值往哪边变大**"；东西半球记"**小小为东、大大为西**"
- 变式提问："（30°W，40°N）在哪个半球？"→ 换成"它对面（穿过地心）那个点呢？"

**鞍部 / 陡崖认错**
- 常见错法：鞍部和陡崖分不清；把"两条等高线之间"当鞍部
- 背后卡点：图形特征没和名字挂上——背了文字没看图
- 补救讲法：特征锁一遍——**两山顶之间的低地=鞍部**（想想马鞍）；**等高线叠在一起=陡崖**
- 变式提问："图上哪适合攀岩？"（陡崖）→ 换成"哪里适合修观景台、一眼看两个山头？"（鞍部）

**气候类型判错（气温降水图）**
- 常见错法：只看最热月就下结论；雨热不同期判成雨热同期
- 背后卡点：没有固定判读顺序，凭印象
- 补救讲法：固定三步——① 看**最冷月**气温定温度带 ② 看**降水怎么配** ③ 再报气候类型名
- 变式提问："最冷月 5°C、夏季干燥——哪个半球？什么气候？"→ 换成"只给气温曲线，至少能定什么？"

**区域特征张冠李戴**
- 常见错法："亚洲地形以平原为主"（实为中间高、四周低）；大洲特征互相记混
- 背后卡点：特征**死背**、没挂在图上——记忆和地图两张皮
- 补救讲法：每条特征配一个"图上的证据"（说亚洲"中间高"→ 指着图上高原的位置说）；练"从图说特征"
- 变式提问："给你一张没写名字的地形图，你怎么猜是哪个洲？"→ 换成"说三个证据支持'非洲是高原大陆'"

**位置描述写不全**
- 常见错法：问"描述位置"只写"它在亚洲"
- 背后卡点：没有描述位置的**固定架子**（想到哪写到哪）
- 补救讲法：给架子——**半球 → 纬度带 → 海陆位置 → 相邻**，每次按架子逐格填
- 变式提问："用四句话说清中国的位置。"→ 换成"哪一句能把它和巴西区分开？"

**材料题不读材料（凭背的答）**
- 常见错法：答案和材料对不上；问"根据材料"，答的却是课本原话
- 背后卡点：把材料题当默写题；没有"圈关键词"的动作
- 补救讲法：答前先做一件事——**圈出材料里的地名、数字、图名**；答完回头对"我这条答案来自材料哪句"
- 变式提问：同一问答两段不同材料，让他指出答案差异来自哪句 → 换成"给材料划出'有用的句子'"

### 高中

**成因分析：自然、人文只剩一头**
- 常见错法：问"分析原因"只写自然因素（或只写人文）；顺序乱
- 背后卡点：没有"两列因子"的检索习惯
- 补救讲法：答前先写两列头——**自然（气地水土生）+ 人文（人口 / 市场 / 交通 / 劳动力 / 科技）**，
  再从材料里挑有依据的条目
- 变式提问："只写人文因素，写三条。"→ 换成"你这条原因属于自然还是人文？"

**模板硬套：答案不贴材料**
- 常见错法：堆模板词，与题目材料和区域对不上
- 背后卡点：把模板当"答案"用，而不是当"检查表"
- 补救讲法：改一个动作——**先圈材料关键词，模板只用来核对"角度漏没漏"**；写完自查"每条都有材料依据吗"
- 变式提问："同一问题换一个区域，模板哪些条目要删？"→ 换成"你这条依据在材料第几句？"

**自然地理：过程链断（说不清"为什么"）**
- 常见错法："这里终年温和湿润"背得出；问"为什么"，接不上
- 背后卡点：纬度 / 环流 / 下垫面的链条没连起来
- 补救讲法：画箭头链（纬度位置 → 大气环流 → 气候特征），**讲一步问一步**；再让他闭卷自己画一遍
- 变式提问："把'终年温和'改成'终年炎热'，链条哪一环变了？"→ 换成"画水循环箭头，标出人类能影响哪一环"

**等值线迁移：等温线、等压线判读**
- 常见错法：等高线的"凸高为谷"会了，到等温线就不会迁移
- 背后卡点：记的是"结论"，不是"通法"
- 补救讲法：教**通法**——"**凸高为低、凸低为高**"（弯曲判高低）；
  再回到等值线三原理（等值、疏密、闭合），最后分别套：等温线（凸高=比同纬度低：地形高 / 寒流）、
  等压线（凸高=低压槽）
- 变式提问："7 月陆地上等温线往哪凸？为什么？"→ 换成"等压线最密的地方，风大还是小？"

**水文特征描述不全**
- 常见错法：描述河流只写"流量大"
- 背后卡点：没有"特征清单"——想到哪写到哪
- 补救讲法：五要素清单逐条过——① 流量 ② 水位 / 汛期 ③ 含沙量 ④ 结冰期 ⑤ 流速 / 水能；
  每条再问"它由什么决定"（气候 / 地形 / 植被）
- 变式提问："南方一条河、北方一条河，各写五条。"→ 换成"有结冰期的河一定有凌汛吗？"

**区位分析漏角度**
- 常见错法：分析农业 / 工业 / 交通区位只答一两个因素（多写"交通便利"）
- 背后卡点：区位因素表没背成"检查表"
- 补救讲法：用清单逐条筛——自然（地形 / 气候 / 水源 / 土壤）+ 社会经济（市场 / 交通 / 劳动力 / 政策 / 技术 / 地价）；
  **先材料、后模板**（同上一张卡的动作）
- 变式提问："换个区域，哪些区位因素要换掉？"→ 换成"你漏了哪个角度？"

**术语口语化失分**
- 常见错法：卷面上写"水多""地不好""这地方热"
- 背后卡点：没有术语替换的习惯；平时说惯了
- 补救讲法：术语替换表 + 写完自查（「练-方法与配比」第三节每天 3 句）；
  答案里每个形容词都问一句"课本怎么说"
- 变式提问：把"雨多、地不平"改写成术语版 → 换成"'洪涝的原因'里，哪些词必须用术语？"

## 三、知识树骨架（板块级，用于诊断定位；不是单元清单）

> 要精确到单元，得查教材（人教版）。

- **初中**（人教：七上→七下世界、八上→八下中国）：
  地球与地图（地球仪 / 经纬网 / 地图三要素 / **地形图判读**）→
  世界地理（海洋与陆地 / 气候 / 居民 / 认识大洲—地区—国家）→
  中国地理（疆域与人口 / 自然环境 / 自然资源与经济 / 认识区域）。
  2022 版课标改按"**认识全球 + 认识区域 + 地理工具与地理实践**"组织——内容还是那批，换了编排。
- **高中**：地理1（自然：宇宙环境 / 大气 / 水 / 地貌 / 植被土壤 / 自然灾害）→
  地理2（人文：人口 / 城乡 / 产业区位 / 环境与发展）→
  选必1（自然地理基础：地球运动 / 物质运动与能量交换 / 整体性与差异性）→
  选必2（区域发展）→ 选必3（资源、环境与国家安全）。
- **四素养是同一套、不分学段**：初高中都是人地协调观 / 综合思维 / 区域认知 / 地理实践力——
  **区别在内容的深度和尺度**，诊断时别把"高中才学的成因链"当成初中该会的。

## 四、超纲红线（收材料、出题之前过一遍）

- 边界口径：初中按义务教育地理课程标准（认识全球 / 认识区域）；高中按必修 / 选择性必修。
- 辅导班 / 复习资料常"提前教"——**收进来之前过一遍学段边界**；拿不准的先别用。
- 已知的常见提前教（示例，**逐条以课标为准**）：
  - **气压带风带、季风成因** → 高中；初中只到"气候类型分布与特征"
  - **正午太阳高度变化与计算** → 高中；初中只到"地球运动产生哪些现象"
  - **等值线通法（等温线 / 等压线判读）** → 高中为主；初中基本只练等高线
  - **洋流**：初中基本不要求洋流名称与成因——**这条各地要求有差异，拿不准先别教**
