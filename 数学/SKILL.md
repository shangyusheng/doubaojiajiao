## 二、数学的错分四种

| 类别 | 孩子会怎么说 | 怎么补 |
|---|---|---|
| **概念没懂** | "不知道这题在说什么" | 回去讲概念——**刷题没用** |
| **方法不会** | "知道要干什么，但不知道从哪下手" | 讲方法 + 练同类题型 |
| **审题错** | "看漏了""理解错问什么了" | **练读题**（第三节有按学段的具体做法） |
| **计算错** | "我会做，就是算错了" | 练计算（口算/竖式专项） |

**数学最容易混的两个**：

- **"不会"和"看错了"是两回事** —— 让他把题**复述一遍**，就知道是哪一种
- **计算错不是"粗心"** —— 粗心没法补；要落到"**哪一步算错的、为什么**"，然后练那一步

## 三、数学怎么讲

> **展开版在 `references\讲-方法与话术.md`**：讲一道题的完整流程（每一步问什么）、
> 四条数学思想的例子、画图怎么分三步教、几何辅助线套路、高中得分点清单、**带图的题怎么兜底**。
> **这里有的，那里不重复。**

### 共同的三条（不分学段）

1. **先给他选项**（照第二节四类），别让他自己想说
2. **讲一小步就问"这一步懂了吗"**（懂了 / 有点糊 / 还是不懂）——**"有点糊"那一档必须留着**
3. **说"不懂"就换个说法**（不许重复原话）；**最后一步（算出结果）留给他**

**"换个说法"有哪些换法**（他卡住就一条条往下试；括号里是例子）：

| 招 | 怎么用 |
|---|---|
| **类比** | 找一道结构相像的旧题套过来（分式化简 类比 分数约分） |
| **辅助元素** | 添一条线，或设一个中间量（换元，令 t = x²） |
| **辅助题目** | 先做个小铺垫，它的结论是大题的台阶 |
| **从后往前** | 从结论倒推"要得到它，得先有什么" |
| **特殊化 / 一般化** | 先拿特殊值试规律，或把条件放宽看结构 |
| **回到定义** | 性质记混了，退回最原始的定义重想 |
| **重新叙述** | 用自己的话、或用数学符号，把题再讲一遍 |

**换的方向**是四条数学思想：**函数与方程 / 数形结合 / 分类讨论 / 转化与化归**。

> **能说出来才算真会**：讲完让他**用自己的话把思路说一遍**。
> 说不清的地方就是没懂的地方——比再讲一遍有用。

### 小学：先立审题习惯

> **小学应用题失分，大头不在"不会算"，在"没读懂题"。**

- **四步审题**：① 划关键词（过滤没用的信息）② 圈出已知量和未知量 ③ **锚定最后问什么**（防止答非所问）④ 找隐藏的数量关系
- **"三读一转"**：通读 → 精读并圈画 → 对着问题再读一遍；然后**把文字翻成算式**
  （"甲比乙的 3 倍多 5" → 甲 = 乙 × 3 + 5）
- **画图建模**：线段图、示意图。**画图优先于刷题**——漏条件的根子是信息太多理不清，画图能把思路摊在桌上
- **单位先行**：先统一单位——**不少"计算错误"其实是单位没统一**
- **限时审题**：低年级 30 秒~1 分钟、中高年级 1~2 分钟。养成"**慢审题、快解题**"

### 初中：先做"情景识别"

- **解题第一步不是列式，是判断这是哪类模型**（方程 / 函数 / 几何证明 / 统计）——这一步叫"情景识别"
- **几何**：先把已知标在图上、看清要证什么，再想"哪些定理能把已知和结论连起来"
- **函数**：先看图像（增减、交点、范围），再看式子
- **应用题**：**多步题拆成几个"一步题"，从问题倒推**需要什么条件

### 高中：先看结构，再动笔

- **先判断在哪个板块**（函数与导数 / 数列 / 三角 / 立体几何 / 解析几何 / 概率统计），再调对应的思路
- **导数和数列重"结构"**：先看式子的结构（是不是等差等比、能不能构造），**不要上来就硬算**
- **解析几何**：先画图定位置关系，再设坐标——避免"一上来就算"

> ⚠️ **大学位（高数）预留**：微分、积分、线性代数、概率论——各自"先判断类型再动"的逻辑写在这一节。
> **加大学 = 在这一节下面再添一节，不动别的。**

## 四、数学怎么练

> **展开版在 `references\练-方法与配比.md`**：**计算错到底怎么补**（草稿规范 / 强制验算 / "慢即是快"）、
> 三个学段各自多出来的一条、一题多解、几条例子。**这里有的，那里不重复。**

### 共同（不分学段）

- 讲完一道题 → **同类变式题 1-2 道**（改数字、换情境，**不是原题**）
- **同类错因隔天 3 题复测**，对了再升难度
- **大题从够得着的那一问开始**（五档降级见「复习账本」第九节）
- **每天 10 分钟"保质"练习**：10 道题，目标全对——**不是题海**，**这 10 道就是那天的量**（不在「每日练习」的份外再加）。
  错了先分"**是法则没掌握，还是会做但算错了**"，再对症练（**别写"粗心"**——见第二节）
- **计算错的补法**（草稿怎么打、验算用什么抓手）在 references 那份——**不是"细心点"就完了**（见第二节）

#### 难度：三档，但配比要按孩子调

| 档 | 是什么 | 干嘛用 |
|---|---|---|
| **基础** | 他会的 | 热身、稳住基本分 |
| **巩固** | **刚好不会那条线** | **出题主力**——找的就是这条线 |
| **拔高** | 够一够能到的 | 往上顶 |

**配比不固定，看孩子**（「教材同步」那个 40/40/20 是给**中等水平**的默认值）：

- **基础薄弱** → 基础多，**拔高几乎没有**（先补齐，顺带重建信心）
- **中等** → 基础 40% + 巩固 40% + 拔高 20%
- **好学生** → 巩固和拔高多，基础只留热身

**拔高的方向：同一个知识点往深走**（变式 / 多解 / 换个问法）。

**其中一条路是"一题多解"**：做完一道题，试另一条路——代数题试几何法、应用题试图表法，
**做完比较哪个更省事**。（例：解析几何既能联立方程硬算，也能用几何性质把运算简化）

> **不往上学段。** 小学的孩子给初中题、初中的给高考题——他缺的是**工具**，不是智力，
> 只会看不懂而挫败。**同知识点的题可以无限往深，跨学段的题再简单也用不上。**

**够不着的题**：降到「看得懂」或「见过」，并**明确说"你现在不用会"**（见「复习账本」第九节）。

> ⚠️ **别把三个"档"混起来——名字像，管的事完全不同：**
>
> | 这个分法 | 管什么 | 写在哪 |
> |---|---|---|
> | **难度三档**（基础 / 巩固 / 拔高） | **出新题时怎么配比** | 就是这一节 |
> | **五档降级**（会做 / 会一半 / 看得懂 / 见过 / 不管） | **面对已有的题：该不该花时间** | 「复习账本」第九节 |
> | **三档判定**（独立做对 / 提示后做对 / 没做出来） | **复习时怎么判、间隔怎么变** | 「复习账本」第二节 |

### 小学

- 口算、竖式、脱式计算专项——**计算过关能稳住大部分基础分**
- 应用题表达：把算式**说成人话**（这一步练的是"读懂关系"，不是"算得快"）

### 初中

- 基础计算 + 方法迁移 + 应用表达
- 错题**按题型归类**——"吃透一类题胜过刷十道新题"

### 高中

- 按板块专项：函数与导数 / 数列 / 三角 / 立体几何 / 解析几何 / 概率统计
- **限时训练**（高中尤其要练时间分配）

## 五、数学怎么诊断（摸底和考试看什么）

> **展开版在 `references\诊断-错因与诊断卡.md`**：四类错因在数学里的具体表现、
> **23 张诊断卡**（小学 5 / 初中 11 / 高中 7，按知识点查：常见错法 → 卡点 → 补救讲法 → 变式提问）、
> 各学段知识树骨架、**超纲红线**。

| 学段 | 看什么 |
|---|---|
| **小学** | 基础计算丢分在哪、应用题读不读得懂、单位/审题习惯 |
| **初中** | 基础题丢分、模型选错、时间够不够 |
| **高中** | 板块薄弱点、结构判断、时间分配 |

**数学还要多看两个抓手**（不算新的错因类别——**记账、给孩子认，永远只有四类**）：
**步骤表达**（跳步、丢采分点）和**时间分配**（难题耗时太多，后面会做的没时间）。

**孩子拿来一道题、或者一道题反复错** → 翻 references 里的诊断卡，对号入座。

**摸底的做法见「摸底」**：一科 6-8 题、**一次只给一道**、从"这一年的中等难度"起步、对加难错降。
