## 一、讲一道题的完整流程

**四步不是走完，是"他卡在哪一步，就在那一步多待一会儿"。**

### 第一步 · 读懂题（先别动笔）

- 问未知量：「最后要求的是哪个量？**用你自己的话说一遍**。」
  （例：题问"还剩多少"，别让他算成"一共多少"）
- 问已知：「题里给了哪些数和条件？圈出来。」
  （例：把"甲有 5 支、乙比甲多 3 支"逐条圈出来）
- 问够不够：「这些条件够求出答案吗？有没有多余的、或者互相矛盾的？」
- 画图 + 设符号：「画张图，未知的设成 x。」（例：行程题画线段图标相遇点）
- 条件分开写：把条件的各部分**一条条**写下来，别糊成一团。

### 第二步 · 找路子（找不到直接的，就找间接的）

**按这个顺序问，一问不行就问下一问：**

1. 「你以前见过它吗？或者见过长得差不多的？」
   （例：这道求最值，像不像课本那道二次函数求顶点？）
2. 「知道一道和它有关的题吗？知道一个可能用得上的定理吗？」
   （例：见中点，想中位线 / 倍长中线）
3. 「能不能用上那道题的结果或方法？要不要添个辅助元素？」
   （例：添一条辅助线构造全等三角形）
4. 「能不能换个说法重讲这道题？回到定义去？」
   （例：把"甲比乙的 3 倍多 5"重述成 甲 = 乙×3 + 5）
5. 还不行就**先做简单版**——更特殊的、或者只满足一部分条件的。
   （例：先试 n=1,2,3 找规律）

> 第 5 条就是「够不着就往下走，不硬讲」在讲题里的用法。

### 第三步 · 动手做（每步回头验一下）

- 「这一步你一眼能看出对吗？能不能证明它对？」
  （例：移项之后，把解代回原方程验一下）

**最后一步（算出结果）留给他**——这是 `SKILL.md` 第三节共同三条里的那条。

### 第四步 · 回顾（做出来别停）

- 「能不能用另一种方法得到同样结果？」（例：代数解完，再用图像核对一下）
- 「这个结果或方法，能用到别的题上吗？」
  （例：这套"设未知数列方程"的思路，下道工程题照样用）

> **第四步就是那条「能说出来才算真会」**——让他用自己的话把思路说一遍。
> 说不清的地方就是没懂的地方。

## 二、"换个说法"往哪换：四条方向盘

`SKILL.md` 第三节有这四条的名字；**这里是各自的例子**——他听不懂时，往这四个方向换：

- **函数与方程** —— 要求的量设成未知数，靠等量关系列式子。
  （例：相遇问题 → 甲路程 + 乙路程 = 总路程）
- **数形结合** —— 代数看不出就画图，图不好算就转成式子。
  （例：解不等式 → 画数轴看解集；一次函数 → 先看图像的增减、交点、范围）
- **分类讨论** —— 条件不确定就分情况，做到**不重不漏**。
  （例：含参方程先分 a=0 与 a≠0；|x−2| 分 x≥2 与 x<2 两种拆）
- **转化与化归** —— 把生题变熟题、复杂变简单。
  （例：不规则图形面积 → 割补成规则图形；分式方程 → 去分母转成整式方程）

> **七招换说法**（类比 / 辅助元素 / 辅助题目 / 从后往前 / 特殊化一般化 / 回到定义 / 重新叙述）
> ——`SKILL.md` 第三节的表里有名字和一句话说明，**这里不重复**。

## 三、小学：把"读题"和"画图"教成习惯

### 画图，分三步走（别一上来就逼他画标准线段图）

**线段图本身就是抽象的**——低年级孩子画不出来，不是笨：

1. **先画实物图**：画圈圈、火柴人代表人、桌子。（例：3 个人就画 3 个圈）
2. **再画半抽象图**：画方块、线段代表数量。（例：一堆苹果画成方块标"10 个"）
3. **最后才画标准线段图**：用长短线段表示数量关系。
   （例："比多比少"画两段——一段一样长，再多出一小截）

### 把数量关系"翻译"成数学语言（从简单到复杂练）

- 差 → `+ / −`；倍 → `× / ÷`；经过时间 → 后 − 前；路程 → 速度 × 时间；
  "几分之几" → 比的关系
- 这一步就是 `SKILL.md` 说的"三读一转"里那个"转"——**转得准不准，靠这里练**。

### 同一个关系，练多种表达（这是"举一反三"的根）

（例：路程 = 速度 × 时间，也能写成 速度 = 路程 ÷ 时间、时间 = 路程 ÷ 速度
→ 遇到变形题他就会反推了）

## 四、初中：几何往前推一步的两个抓手

> `SKILL.md` 第三节写了"先把已知标在图上、看清要证什么，再想哪些定理能连起来"。
> 这里补两个**往下走一步**的东西：

### 几何证明，规范三步

① 写清"求证"的目标 ② 推理，**每一步注明用了哪个定理** ③ 下结论。
（例：证全等 → 先把已知的边角标在图上，再选判定 SSS/SAS/ASA/AAS/HL）

### 辅助线的常见套路

- 见中点 → 中位线 / 倍长中线
- 见角平分线 → 向两边作垂线
- 求斜线段长 → 构造直角三角形用勾股

### 初一最大的坎：代数思维转型

小学是"算术逆推"，初中要转成"设未知数正推"——**"用字母表示数"是那道门槛**，
很多孩子卡在这儿。他卡的时候，别怪他"不会，是没转过弯"。

## 五、高中：多出来的三件事

> `SKILL.md` 第三节写了"先定板块、先看结构"。这里补三件高中特别要紧的事：

- **得分点清单**：每类题的"必写步骤"要背熟，每一步都有定理或公式撑着，
  让阅卷的能一眼找到采分点。
  （例：导数题必写"求定义域 → 求导 → 令导数 = 0 → 列表看符号 → 下结论"）
- **中档题"限时拆题"**：把综合题拆成几个"一步题"，从问题倒推需要什么，一步一步做对。
  **中档题最怕的不是难，是一看到就先放弃。**
- **思想方法要专题化练**：数形结合 / 分类讨论（含参问题要全覆盖）/
  函数与方程（建模、换元、待定系数）/ 转化与化归。

## 六、带图的题怎么办（画图动作 + 兜底句）

> 孩子那边**只有**他打的字、家长转述、拍来的照片——**没有耳朵和眼睛**。
> 数学的图（几何图、格点图、函数图像、立体图形）**大多能让他自己画出来**，这反而是优势。

- **首选动作**：「你先在纸上把图画出来——照题目说的画，画完拍给我；或者你说着画、我来问。」
- **判读动作（三问递进）**：先问"图上有什么"（他认得多少算多少）→ 再问"下一步你想怎么办" → **最后才讲**
- **卷子上印好的图**（格点图、函数图像、几何图）：用他那张（拍来）；看不清就"你说图上有什么 / 横轴纵轴各自是什么 / 哪条边压在哪条边上 / 顶点都标的什么字母"
- **红线**：**不许说"我给你找了张图"**；也不许描述一张没见过、没拍来的图——
  尤其**立体几何的截面、格点图里的阴影、函数图像的交点**，凭空描述等于替他编了一道题。
  **报不出字母和条件的，就先要图，别先讲。**
