## 一、四类错因，在数学里长什么样

> 「复习账本」第八节给的是四类的机制，这里只说**数学里的具体表现**。

- **概念没懂** —— "不知道这题在说什么"。数学的概念断层。
  （例：不懂"函数是唯一对应"、不懂"绝对值是到原点的距离"；高中还有定义域、导数的几何意义、圆锥曲线定义模糊）
  **补法 = 回去讲概念，刷题没用。**
- **方法不会** —— "知道要干什么，不知道从哪下手"。没掌握模型 / 定理的**适用条件**。
  （例：见中点想不起中位线；不知道怎么选全等判定）
  **补法 = 讲方法 + 练同类题型。**
- **审题错** —— "看漏了 / 理解错问什么了"。数学特有的几种：
  漏隐藏条件、单位没统一、把"还剩"看成"一共"、忽略定义域或取值范围。
  **补法 = 练读题**（划条件、圈问句、先复述再动笔）。
- **计算错** —— "我会做，就是算错了"。数学特有的几种：
  符号错、移项不变号、去分母漏乘、通分变号错、特殊值记错。
  **补法 = 计算专项**（见「练-方法与配比」第一节），**不是"细心点"。**

> 这里面最容易混的两对——"不会"和"看错了"、"计算错"和"粗心"——**判法在 `SKILL.md` 第二节**，这里不重复。

## 二、诊断卡（按知识点查）

> 每张卡：**常见错法 → 背后卡点 → 补救讲法 → 变式提问**。
> 用法：孩子拿来的题对上了哪张，就按它的"补救讲法"走，再用"变式提问"验他是不是真懂了。
> 一道题**反复错**的时候也翻这里——多半能对上某一张。

### 小学

**比多比少应用题**
- 常见错法：看到"多"就加、看到"少"就减
- 背后卡点：没搞清"谁和谁比、谁是标准量"，靠字面套运算
- 补救讲法：画两段线段图——**先画标准量（1 倍量），再画比较量**；问"要求的是大的还是小的？"
- 变式提问："红花 20 朵，黄花比红花少 5 朵，黄花几朵？"→ 改成"黄花比红花多 5 朵"让他重画

**多步应用题（过程变化）**
- 常见错法：只算了其中一步就作答（漏条件）
- 背后卡点：没把事件过程读全，急于动笔
- 补救讲法："通读 → 圈条件 → 对着问题再读一遍"（三读），把每一步变化列出来
- 变式提问："妈妈买 10 个苹果，小明吃 2 个，爸爸又买 5 个，现在共几个？"→ 变式："爸爸买的是剩下的一半呢？"

**答非所问**
- 常见错法：题问"还剩多少"，求成"一共多少"
- 背后卡点：没锚定"最后问什么"
- 补救讲法：动笔前**先圈出问句**，做完回头对着问句再答
- 变式提问：同一道题分别问"还剩几个"和"一共几个"，让他体会区别

**单位 / 关键词**
- 常见错法：单位没统一直接算；"增加了"和"增加到"混
- 背后卡点：关键词语义不清 + 没有单位意识
- 补救讲法：先统一单位再算；辨析"增加了（净增）"和"增加到（变成）"
- 变式提问：让他用"增加了 5 米"和"增加到 5 米"各造一句

**计算（退位减 / 表内除）**
- 常见错法：退位减忘退位、口诀用错
- 背后卡点：算理不熟
- 补救讲法：**先讲算理，再练速度**——口算专项（见「每日练习」口算那条）
- 变式提问：同类口算 10 道限时

### 初中

**有理数减法 / 符号**
- 常见错法：(-3)−(-5) 算成 −3−5=−8，或者算成 3+5=8
- 背后卡点：减法法则和加法混淆，"减去一个负数 = 加它的相反数"没内化
- 补救讲法：回到定义——减去一个数等于**加上它的相反数**；用数轴走一遍（从 −3 再向右走 5）
- 变式提问：(-3)−(-5)=? → 改成 (-3)+(+5)=? 让他确认相等；再出 (-2)−(+4)

**一元一次方程移项**
- 常见错法：移项不变号（4x−1=3x+2 → 4x+3x=2+1）
- 背后卡点：把"移项"当成"挪位置"，不懂它是等式性质的结果
- 补救讲法：强调**移项必变号**；用天平、或者"两边同时减同一个数"演示
- 变式提问：4x−1=3x+2（正解 x=3）→ 变式 5x+3=2x−6

**不等式性质 3**
- 常见错法：两边乘 / 除负数时忘了变号
- 背后卡点：只记着"移项变号"，漏了"乘负数也要变号"
- 补救讲法：专列一条"**乘除负数 → 不等号反向**"；用具体数验证（−2<3，两边乘 −1 得 2>−3）
- 变式提问：−2x>6 求解 → 变式 −2x>−6

**分式方程增根**
- 常见错法：去分母后忘了验根，留下增根
- 背后卡点：不知道去分母可能产生让分母为 0 的增根
- 补救讲法：固化步骤"**去分母 → 解整式方程 → 检验（代回最简公分母，看是不是 0）**"
- 变式提问：给一道会产生增根的方程，让他自己验出来并说明为什么舍去

**含参方程 / 分类讨论**
- 常见错法：忽视二次项系数不为 0；两边同除以含未知数的式子时漏讨论
- 背后卡点：**分类讨论的意识缺失**
- 补救讲法：见"含字母系数"先问一句"**它能不能为 0？**"；消元降次时消掉带 x 的公因式，要回头检验
- 变式提问：ax²+bx+c=0，先分 a=0 与 a≠0

**几何证明（全等 / 相似）**
- 常见错法：步骤跳跃、定理张冠李戴、辅助线不会添
- 背后卡点：没有"已知 ↔ 结论"的链路意识
- 补救讲法：规范三步（写求证 / 推理注明定理 / 下结论）；**先把已知标在图上**；
  辅助线套路见「讲-方法与话术」第四节
- 变式提问：同一个图形换一组已知，让他重新找全等

**圆中的线段计算（垂径定理 / 弦心距）**
- 常见错法：见到弦、拱高、半径的题无处下手，直接量 / 猜，不构造直角三角形
- 背后卡点：垂径定理没变成动作——**见弦就要想到"弦心距 + 半弦 + 半径"那个直角三角形**
- 补救讲法：固化两个动作——① 见弦（或中点、拱高）**先作弦心距**（圆心向弦作垂线）② **连半径**凑出直角三角形（半径² = 半弦² + 弦心距²）；拱桥 / 圆材题先把这幅图描出来再代
- 变式提问：给半径和弦长求弦心距；给拱高和跨度求半径（赵州桥式）

**圆周角 / 圆心角 / 圆内接四边形**
- 常见错法：求角时找不到"同弧所对的圆周角 / 圆心角"；忘了**直径所对的圆周角是直角**；圆内接四边形忘了对角互补
- 背后卡点：没有"先在图上标弧"的习惯——角与弧的对应是靠找的，不是靠背的
- 补救讲法：三步走——① 求角先问"这个角对着哪条弧"（同弧：圆周角相等、圆心角是圆周角的 2 倍）② **见直径先标直角**（90° 的圆周角所对的弦是直径）③ 是圆内接四边形就直接用"对角互补"
- 变式提问：给圆周角求同弧的圆心角；圆内接四边形给三个角求第四个；直径 + 一角的题

**切线的判定与性质 / 切线长定理**
- 常见错法：证切线时不交代"经过半径外端"；"有切点 / 没切点"两类题用同一条路；切线长定理题不会拆周长
- 背后卡点：切线的两条路没分清——**有切点：连半径、证垂直；没切点：作垂线、证"距离 = 半径"**
- 补救讲法：做题先判"题里画没画切点"，再走对应那条路，每一步都补上"经过半径外端且垂直于半径"；"圆外一点引两条切线"的题用**切线长相等**——能拆周长、证线段相等
- 变式提问：给三角形周长和某边，求切线段拼出的周长；两道证切线题（分别从有切点、无切点起步）

**弧长、扇形与圆锥**
- 常见错法：弧长公式与扇形面积公式混；圆锥题里把**母线当成底面半径**；阴影（不规则）面积硬算
- 背后卡点：几个公式各自"是谁的一份"没分清；不认得"不规则图形 = 整体 − 空白 / 割补 / 等积移"
- 补救讲法：一条线串起来——弧长是**圆周长的一份**、扇形面积是**圆面积的一份**（都按 360 分）；**圆锥侧面展开就是扇形：母线 = 扇形半径，底面圆周长 = 弧长**（这条对应关系是圆锥题的总钥匙）；阴影面积先问三句："整体减空白？割补？等积移？"
- 变式提问：给圆心角和半径，求弧长 / 扇形面积 / 围成圆锥的侧面积；格点图阴影面积

**函数（一次 / 反比例 / 二次）**
- 常见错法：待定系数的个数和点值对不上；忽略自变量取值范围；图像和性质脱节
- 背后卡点：数形结合没建立起来
- 补救讲法：**有几个待定系数就要几个点**；先画图看增减、交点、范围，再算
- 变式提问：给图像让他说性质；给性质让他画草图

### 高中

**函数定义域 / 值域**
- 常见错法：求解析式或最值时忽略定义域、忽略边界值
- 背后卡点："先求定义域"没变成第一步的条件反射
- 补救讲法：固化成"函数题第一步先写定义域"；得分点清单见「讲-方法与话术」第五节
- 变式提问：同一个函数限制定义域之后再求最值

**导数（复合求导 / 极值）**
- 常见错法：复合函数忘了链式法则；求极值忽略导数符号变化
- 背后卡点：求导法则不熟 + 没理解极值的本质是**导数符号变化**
- 补救讲法：链式法则"**由外向内，一层层求**"；极值必"**列表看导数左右符号**"
- 变式提问：给一个复合函数求导；给导函数图像判断原函数的极值点

**数列**
- 常见错法：忽略 n 的取值范围（n=1 与 n≥2 要分开验）；等差等比求和公式混；递推关系没找准
- 背后卡点：通项与前 n 项和的关系（aₙ=Sₙ−Sₙ₋₁ 需要 n≥2）没内化
- 补救讲法：见"由 Sₙ 求 aₙ"，**必先分 n=1 和 n≥2**；先判类型再套公式
- 变式提问：给 Sₙ 求 aₙ → 变式给递推关系求通项

**三角函数**
- 常见错法：解三角方程忽略周期性（漏解）；特殊值符号记错；值域范围不清
- 背后卡点：周期性与象限符号的意识弱
- 补救讲法：解三角方程**必写"+2kπ"通解**；用单位圆定符号
- 变式提问：sinx=1/2 在 [0,2π] 上和在整个实数上分别求解

**立体几何**
- 常见错法：空间想象不足导致截面 / 体积算错；点线面关系不会综合；展开图忽略侧面积
- 背后卡点：空间观念弱 + 证明链路不清
- 补救讲法：**先画图或者建系**（空间向量）把关系标清；平行垂直的判定定理逐条对
- 变式提问：同一个几何体换一个截面再求

**解析几何（圆锥曲线）**
- 常见错法：离心率 e=c/a 的范围记错（椭圆 0<e<1）；方程变形失误；
  直线与曲线的位置关系忘了用判别式；焦点 / 准线混淆
- 背后卡点：定义和标准方程不熟 + 运算量大容易崩
- 补救讲法：**回到圆锥曲线的定义**；联立之后先看判别式再算；运算分步不跳（见「练-方法与配比」第一节）
- 变式提问：给离心率求方程；判断直线与椭圆有几个交点

**通用（时间 / 规范）**
- 常见错法：难题耗时过多，后面会做的没时间；跳步骤丢采分点
- 背后卡点：时间分配 + 规范意识
- 补救讲法：限时训练；得分点清单（每一步都有依据）；**先易后难**
- 变式提问：整卷限时，让他自己记录每题耗时

## 三、各学段知识树骨架（用来定位，不是单元清单）

> ⚠️ 这是**板块级**的粗骨架，够用来定位"他这块弱"。**要精确到单元，得看他课本。**

- **小学**（1-6 年级）：数与运算（整数 / 小数 / 分数四则、口算竖式）/
  数量关系（和差倍、行程、工程、单价数量总价）/ 图形（周长面积体积、角的度量）/
  统计初步 / 常见的量（单位换算）
- **初中**（7-9 年级）：数与式（有理数 / 整式 / 分式 / 二次根式）/
  方程与不等式（一元一次 / 二元一次 / 一元二次 / 不等式组）/ 函数（一次 / 反比例 / 二次）/
  图形（三角形全等相似 / 四边形 / 圆 / 图形变换）/ 统计概率
  **难点**：代数思维转型、几何证明、函数数形结合、二次函数压轴
- **高中**（必修 + 选择性必修）：六大板块——函数与导数 / 三角函数与解三角形 / 数列 /
  立体几何 / 解析几何（圆锥曲线）/ 概率统计；另加集合与逻辑、不等式、平面向量、复数
  **难点**：含参讨论、恒成立与零点、数列放缩、解析几何综合运算、导数压轴

**素养的学段递进**（用来判断"他缺的是意识层还是能力层"）：
小学重"**意识**"（数感 / 量感 / 符号意识 / 空间观念 / 几何直观）→ 初中重"**观念和能力**"→
高中六核（数学抽象 / 逻辑推理 / 数学建模 / 直观想象 / 数学运算 / 数据分析）。
**小学别拔到高中的抽象要求**（防超纲）。

## 四、超纲红线（拿它过滤网上找来、辅导班给的东西）

- **课标四学段**：第一学段（1-2 年级）/ 第二学段（3-4 年级）/ 第三学段（5-6 年级）/
  第四学段（7-9 年级）；高中另按必修 / 选择性必修。
- **过滤规则**：辅导班和网上的东西常"提前教、超纲"，收进来之前一律用学段边界过一遍——
  - "小学就用方程解应用题" → **超纲**（方程是第四学段）。小学用算术、画图
  - "初中讲导数" → **超纲**（导数是高中）
  - 负数、"用字母表示数" → 第四学段（初一）才正式引入，**小学不提前**
- 这就是 `SKILL.md` 第四节那条「**不往上学段**」和"够不着就降到看得懂 / 见过"
  （「复习账本」第九节）的底气。
