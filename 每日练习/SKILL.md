# 每日练习

**每天几分钟，一次只练一个小目标。** 练到孩子烦了，就不叫"每日"练习了。

**通用开头（每次都要）**：先确认**今日目标、给法和题量**——只练一个目标。

**上下文从「每天学习」传过来**：被调到时，当前科目和年级已经确定（从 `档案.md` 和 `学科/<科目>.md` 读到的）。**不要写死菜单，按科目+年级生成选项。**

**都要给选项，别让他自己想看**（也**不要列成参数表**，就三四个小选择）：

> - 今天练什么？（**按当前科目和年级，只列相关的 2-3 个**，见下面对照表）
> - 怎么来？○ 出一套卷子（一次给全）　○ 一道一道来
> - 来多少？○ 少一点（10）　○ 照常（15）　○ 今天多练会儿（20）
> - 上次那个再来一遍吗？○ 好　○ 换个新的

### 开头选项对照表

| 科目 + 年级段 | 给的选项 |
|---|---|
| 数学 · 小学 1-3 年级 | 口算、应用题 |
| 数学 · 小学 4-6 年级 | 计算、应用题、读题、图形与统计 |
| 数学 · 初中/高中 | 基础计算、方法迁移、应用表达、读题 |
| 语文 · 小学 | 听写、背诵、阅读 |
| 语文 · 初中/高中 | 背诵、文言文、现代文阅读、作文素材 |
| 英语 · 小学 | 单词、跟读 |
| 英语 · 初中/高中 | 单词、句型、语篇阅读 |
| 物理/化学/生物 | 概念辨析、计算、实验/图表 |
| 历史/地理/政治 | 知识回忆、材料题、表达 |

**规则：只列当前科目对应的，别的科目不出现。** 孩子学数学时不该看到"听写""单词"。

### 两种给法（出卷 / 一道一道）

| 给法 | 怎么走 | 什么时候默认 |
|---|---|---|
| **出卷**（一次给全） | 标题 + 题号 + 一句"答案写纸上拍给我，或打字发我"；交卷后批——**只报"对 X、错 Y"**；错的**当场转「讲题」一道道讲**（讲是对话式）；照常记账 | 口算 / 计算 / 听写 / 单词（练流畅度，不打断） |
| **一道一道** | 出一道答一道、答一道反馈一道——**讲就在当场发生**；错的照常进账本 | 应用题 / 方法迁移 / 阅读 / 表达（要看他卡在哪一步） |

**说了怎么来就按说的；没说，按上面的默认。**

**出卷自检（发出去之前过一遍）**：题量对得上选的档；难度配比对（基础 / 中档 / 带坑）；没有超纲；**每题都有答案，而且答案要独立验一遍**——隔开第一遍、重新算（能代回就代回），对不上就**换一道**，别硬发。

**交卷容错**：他报答案缺了哪几道，就直说"**第 3、7 题的答案没看到**"——**别把没报的当错**。

**答案页（家长版）**：出卷时另给一页"**家长版答案**"（排在卷子后面、单独一块）——这页是**给家长的**：想留底就截图；**交卷前别给孩子看**。孩子交卷后照旧只报"对 X、错 Y"，错的转讲题。

### 题量与难度

- **题量**：少一点 10 · 照常 15 · 多练会儿 20（低年级往小走；应用题这类按 **3 道**这种小数量）。**说出来就是承诺**。
- **题型配比（卷面结构）**：出卷要"**像一张真卷子**"——按这科学校卷子的常规结构组卷（填空 / 选择 / 计算 / 解答各几道）。拿不准用通用版：**小学数学 = 口算 8 + 填空 4 + 选择 4 + 应用 3；初中理科 = 选择 5 + 填空 4 + 解答 4**。
- **难度**从年级 + 水平区间 + 薄弱点定；**连对 → 下一组同知识点升一档**（基础 → 中档 → 带坑）。
- **练稳了**（这个块连续独立全对）→ **问一句**"要不要往前带一点（第 X 单元）？"——**家长点头才走**；往前带做**轻铺垫**（下一单元的基础计算 / 核心概念自测），不完整授课。带了就写进 `学科/<科目>.md` 的可选小节 `## 练到`（**「学校进度」不动**——那个字段只管学校教到哪）。

### 三条护栏

- **数量是承诺**：说 10 道就 10 道，**全对也不加**（加量是变相罚"做得快"）；状态好体现在同样数量里**难度上移**。
- **错了提前收**：连着错 2 道、或同一个错因又犯 →"今天到这，剩下的不算数"；明天换练法或降一档。
- **不打分**：只报"对 X、错 Y"——分数、排名那套不做。

**说话像老师**——讲解一句一步、批改"先对后错再给动作"、表扬要具体（规矩见「每天学习」第五节）。

**通用收尾**：错的地方安排到下一次复现，**不重复做对的**。

## 一、小学常用练法（只在对应科目时出现）

### 口算
确认年级和计算范围 → 生成短组口算题（**题量/给法照上面的通用规则**；低年级不超过 20 道）→ 发卷时附**家长版答案页**（见上；交卷前别给孩子看）→ 交卷后批 → **按错误分类** → 安排下一组针对练习

### 听写
筛选今日词语 → **先读音和词义**（不是直接听写）→ 生成听写顺序 → 给订正方式 → **用短句检查会不会用**

### 背诵
**这里只管"今天背哪一段、背下来没有"**：圈定段落 → **用遮挡和复述验一遍** → 没过的明天再来。

> **怎么才记得住（理解着记、按意义分段、关键词线索、间隔复习）是 `agent-memory-method` 的活**——
> 孩子说"背了就忘""记不住"，走它，别在这儿另凑一套方法。
> **不许直接让孩子死背。** 不理解就背，背完就忘，而且忘得比谁都干净。

### 单词
**已经学过的词，练到熟**：按主题分组 → 提醒**发音和拼写易错点** → 听写 / 选择 / 造句**混合练**（不是只背中英对照）→ 记录易混词 → 安排复习

> **要记住一批新词**（"这单元的词还没背"）→ `agent-memory-method`；这里练的是学过、但还不熟的那些。

### 阅读
先确认文章大意 → 设计**找信息 / 推断 / 表达**三类问题 → **要求答案回到文本依据** → 讲解错误原因 → 给一个表达提升小任务

### 读题（只读不做，各学段都用）

**什么时候来**：账上"**审题错**"是最多的那一类时（见「复习账本」第八节）；或者他做题总是"看漏了"。

**3 天，每天 3 道，只读不做：**

1. **圈条件**——数字和限制词圈出来（"至少""原来"）；
2. **圈问句**——他到底要我求什么；
3. **用自己的话说一遍**："这题让我先……再……"。

说得出来 → 直接下一道（**不用做出来**）；说不出来 → 就停在这道，带他读一遍，明天再来。

**过关**：3 天里有 1 天三道都能复述出来——够用。之后做题前，让他开工第一句先说"这题让我干嘛"。

## 二、各科随堂短练（初高中）

**框架一样**：回忆 → 混合练 → 标错因 → 安排复现。**练法按科目换**：

| 科目 | 先让他回忆 | 练什么 | 反馈重点 |
|---|---|---|---|
| **语文** | 2-3 个回想问题确认字词/文本/表达目标 | 拆成**读准、写对、找依据、说完整**四类小任务 | 指出**一个最影响得分**的表达或书写问题 |
| **数学** | 用 3 道代表题快速判断是**四类里的哪一类**（概念没懂 / 方法不会 / 审题错 / 计算错，见「复习账本」第八节） | 基础计算、方法迁移、应用表达 | **必须标出错因**，不能只说对错；同类错因**隔天 3 题复测**，对了再升难度 |
| **英语** | 确认练单词/句型/语篇，主动回忆含义或用法 | 听写、选择、补全、造句、短阅读混合 | **归到四类**：不会读、不会拼 → 表达不完整；不会用 → 方法不会；语法搭配 → 概念没懂 |
| **物理** | 说出现象、条件和要判断的物理量 | 概念判断、模型选择、图像读取、**一题一模型** | 指出**公式的适用条件和物理意义** |
| **化学** | 确认练的是物质性质 / 方程式 / 实验 / 计算 | 把**宏观现象、微观解释、符号表达**放在同一组 | 指出现象描述、方程式或推断链的具体错误 |
| **生物** | 回忆核心概念、结构或实验目的 | 概念辨析、图表读取、实验变量判断、生活应用 | **回到证据和因果关系，不能只背名词** |
| **历史** | 回忆时间、人物/事件、一个因果关系 | 时间排序、因果解释、材料提取、简答表达 | 指出史实、材料依据或表达结构的问题 |
| **地理** | 确认地图/区域/图表类型和要解释的现象 | **定位 → 读图 → 成因 → 影响**四步短题 | 指出读图依据和因果链是否完整 |
| **政治** | 确认主题概念、材料情境和题目要求 | 概念判断、材料关键词提取、小段表达 | 看**观点是否贴材料、表达有没有层次** |

**错的怎么处理**：转成卡片或复习点，进「复习账本」，下次换新情境再测（**不是重做同一道**）。

## 三、和这套东西怎么接

- **谁会把这里调过来**：「每天学习」第二节的调度表——孩子/家长说"练一下""练几道口算""听写一下"。**数学 / 物理 / 地理的短练是各自科目技能调过来的**（它们已经带来这个孩子的薄弱点，按给的出题，别另起一套）。
- **被调到时上下文已确定**：科目和年级从「每天学习」读的档案里来，**不要重新问家长"你要练哪科"**——刚说完"练一下数学"再问一遍是废话。
- **练完记账**：按「每天学习」第六节，错的进错题文件、练了什么写进记录——**写清做几道 / 对几道 / 错几道**（短练是"做过的题"的最大来源，统计就靠这行）。
- **和 `agent-weakness-boost` 的分工**：这里是"每天固定练几分钟"的日常节奏；weakness-boost 是"某个知识点反复错"的专项补，两者不重叠。
- **和「教材同步」的分工**：教材同步管“跟着课本进度学新内容”；这里管“学过的东西每天练一练保持手感”。
- **和 `agent-memory-method` 的分工**：**要记住新东西、或者说"记不住""背了就忘" → 走它**（那是方法问题）；这里练的是**已经学过、还不熟**的（那是熟练度问题）。孩子说"练一下单词"拿不准是哪一种，问一句"这些词老师教过了吗"。
- **和「阅读写作」的分工**：这里的“阅读”是每天几分钟的短练（一篇短文 + 3 道题）；「阅读写作」是“这篇文章读不懂 / 这篇作文怎么写”的完整教学。

## 四、红线

- **一次只练一个小目标** —— 目标多了等于没练
- **反馈必须标错因** —— 只说"对/错"等于没反馈
- **难度不能跳级** —— 跳了就挫败
- **答案必须能核验** —— 有标准答案的让家长扫一眼
- **题量按年级** —— 小学生一次 8-12 道或 15 分钟，低年级更少
- **选项按科目过滤** —— 学数学的孩子不该看到"听写""单词"
