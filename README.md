# 孩子专属学习助手 — 安装和使用说明

> **这不是要装的软件**：不用装任何东西、不用敲命令。装它 = 把技能文件夹拖进豆包 + 粘一段话。

## 一句话说清这套东西

**一个管家 + 一群老师。**

- **管家**（10 个技能）负责记和调度：你孩子几年级、用的哪本书、学到哪了、错过什么、哪里快掉队了、**什么时候该复习什么**；也负责按课本教、考前突击、每日练习、阅读写作、换名师的路子讲题
- **老师**（10 个技能，名字都以「**老师·**」开头，比如「老师·讲题」「老师·预习」「老师·错题」）负责具体怎么讲：每一种都有专门的一套本事

**你只跟管家说话。** 它会看你家孩子的情况，自动叫对应的老师来；老师教完，管家自己记下来。

**你不用记"哪个功能该说什么词"，也不用在装好的那 23 个技能里挑一个来点。**
**入口只有一个：聊天框。**（第二步结尾专门讲了这件事，装完先看那段。）

---

## 开始之前：先切到「本地电脑」

豆包工作有两种干活的模式，**必须用「本地电脑」**：

- **本地电脑** ✅ —— 能读写你电脑里的文件（错题本、记录都在这儿）
- **云电脑** ❌ —— 碰不到你电脑里的文件，这套东西跑不起来

**怎么切**：左下角「工作任务」→ **对话框顶部**那一排里找到「**本地电脑**」，选它（那儿可能写着「云电脑」，点一下就能换）。

⚠️ **用本地模式时，电脑不能休眠**，睡了任务就停。建议去设置里把自动休眠关掉。

---

## 第一步：建一个项目（只做一次）

**项目 = 你电脑上的一个文件夹。** 建好之后，AI 只碰这个文件夹，不动你电脑上别的东西。

1. 先在你电脑上建一个文件夹，比如 `D:\孩子学习`
2. 在豆包工作里新建项目，名字叫「孩子学习」
3. 创建时选择那个文件夹

**权限只给这一个文件夹**，不要图省事把整个桌面或者 D 盘都交进去。

---

## 第二步：装技能（拖一个文件夹）

压缩包里就**一个文件夹**：

| 文件夹 | 数量 | 装不装 |
|---|---|---|
| **0-必装** | 23 个 | ✅ **全部装上** |

**怎么装**：

1. 左边栏找到「**技能 · 连接器 · 伙伴**」，打开「**我的技能**」
2. 点「**新建**」→「**上传技能**」
3. **把「0-必装」里的全部技能拖进去**（一次可以拖多个）
4. 装完**完全退出豆包工作，再重新打开**——重开后**先回到「孩子学习」项目**再说别的（第三步开头有提醒）

> **就这些，没有别的事了。** 初中高中的各科、课本同步、每日练习、考试突击、阅读写作——**全都在「0-必装」里**。
>
> **如果你是从 GitHub 仓库下的，不是压缩包**：没有 `0-必装` 这一层，23 个文件夹直接在最外层——
> 照仓库里的 `安装.md` 走，别去找 `0-必装`。
>
> **装完先别急着找"该点哪个"——看下面那一段「装完你会看到 23 个技能」。**
>
> **⚠️ 这一版还是试水版**（2026-09-17 起）：学科技能做到 **`数学` `地理` `物理`** 这一批。
> 孩子学这三门时，会读专门的方法（怎么讲、怎么练、怎么诊断）；
> **学语文英语、化学历史政治时还没有这层**，只能用通用流程——**不够好，所以要等下一版**。别拿它当"全套都做完了"。
>
> **想省事？** 最后「附：让 AI 帮你装」有一句话的装法——豆包也能试（它那版能上网才行）；
> 别的 AI（Claude Code、Cursor、Codex 这类）能自己装完。
> 但**孩子自己用**这条路先只在豆包工作上开：别的 AI 能装，那条路还没验过。

### 装完你会看到 23 个技能——那一页不是让你挑的

**「我的技能」那一页是"管理页"**：它管的是"装了什么、删哪个、更新哪个"，
**不是"现在开始学哪个"**。所以别在那一长串名字里找该点哪个——**找不到不是你的问题，本来就没有那个按钮。**

**真正的入口只有一个：聊天框。**

回到「孩子学习」项目，在对话框里直接说人话：

> 今天学数学

或者拍一张题的照片发过去，说一句：

> 这道题不会

**剩下的它自己找**：该叫哪个老师、该记哪本账、几天后该回来重做，都是它的事。

**这些技能里，你真正要认识的只有下面这几个名字**（都是管家）：

| 名字 | 什么时候用 |
|---|---|
| `认识孩子` | 装完第一次：建档案（说"建档案"） |
| `摸底` | 建完档案：看孩子底子（说"开始摸底"） |
| `开工` | 摸完底：算该补什么 + 带你填那段设置（说"开工"） |
| `每天学习` | **以后每天**：它就是日常那个入口 |

**其余的你不需要认、也不需要主动叫**（`复习账本` `名师方法` `教材同步` `考试突击` `每日练习` `阅读写作`、
`数学` `地理` `物理`，还有 10 个「老师·」开头的）——它们是管家叫来干活的，不是给你点的。

> 前三个（`认识孩子` `摸底` `开工`）**配置完就没用了**，删不删随你（删了不影响日常）。
> 留着也行，只是列表长一点。

## 第三步：建档、摸底、开工（分几天做也行）

**三步走完，还有一段话要往豆包设置里填**（只做一次，③ 会带你填）。

**在哪儿**：豆包设置里（**不在某个项目下**——它对所有项目都生效）。
**原文**：在下面 ③ 那一段里，**照抄，一字不改**。
**不填会怎样**：孩子直接拍一道题时，AI 可能跳过"管家"直接讲——**讲完了，但没人记账**。

> **⚠️ 说下面这些话之前，先回到第一步建的「孩子学习」项目里。**
> 第二步结尾你重启过豆包，它可能停在别的地方（或者停在某个新对话里）。
> **这一整步都在这个项目里说**——档案、错题本都要建在这个项目绑的那个文件夹里。
> 进错地方，档案就不在那个文件夹里，**以后每天学习的对话读不到它**（它不会拦住你，你自己也看不出来）。

**① 建档案** —— 对 AI 说：

> 建档案

它一句一句问你，五分钟完事。这一步你自己做就行，孩子在不在都行。

> **课本版本它会先填好默认值让你确认**（语文全国统编不用问，数学默认人教版、英语默认人教PEP），
> **不对的才改**——大部分情况你直接点"都对"就行。

**② 看底子** —— 找个孩子有空的时间：

> 开始摸底

它会**把课本的单元列出来让你选"学到哪了"**（不用翻书、不用拍照），然后出题看底子。

> **对不上怎么办？** 如果它列的单元和你孩子的课本不一样（冷门版本、或者教材刚改版），
> 选「其他」，拍一张目录页给它就行——**它会按你的课本走。**

摸底期间它**不讲题、不给答案**——**现在是在量身高，讲了他就不准了**。做完一科可以歇会儿，下次说"继续摸底"接着来。

**③ 开工** —— 说：

> 开工

它会算清楚哪里快掉队了、这周该补什么，然后带你**给每一科建一个对话**。

**它还会让你往豆包设置里填一段话——这一步别漏。**

那段话填进**豆包的「工作任务偏好指令」**（在设置里找，不在某个项目下——它对**所有**项目都生效）。

> **为什么非填不可**：孩子直接拍一道题时，AI 可能跳过"管家"、直接叫讲题技能——**讲完了，但没人记账**。这段是拦不住的兜底。
>
> **它是"软"的**：开头那句"无关就忽略"靠 AI 自觉，不是硬挡。万一它在别的项目里也冒出来了（比如你整理表格时它提醒你记账），**删掉这段就行**——日常学习照样跑，只是孩子直接拍题时可能不记账。

原文就是下面这段，**一字不改**：

> 【孩子学习专用】仅当任务涉及「孩子学习」文件夹、孩子的学科题目、错题、讲题、摸底、复习时，以下才生效；与这些无关的任务，请完全忽略本段。
> - 一次学习结束必须记账：讲过的题按**题目所属科目**写进对应错题本、学了什么写进记录、薄弱点更新——不管用的是哪个技能、在哪个对话。

**以后想改、想删、或者换了电脑要重填，就来这儿抄**——原文一直留在这份说明里，不用回头翻「开工」（那个技能删了也不影响）。

## 以后每天：学哪科，进哪个对话

**一个科目一个对话**——学数学就点「数学」那个，学英语就点「英语」那个。

进对话之后**正常说话就行**，不用背什么词：

| 你说 | 它做什么 |
|---|---|
| **今天学数学** | 先回顾上次错的题，再讲不会的 |
| **我有题不会**（拍照给它） | 讲这道题——**先看你卡在哪，再决定讲多少**。你还能自己往下走，它会给你几个选项让你点（"不知道这题在说什么""我会做，就是算错了"…）；你完全不会，它就直接讲 |
| **明天要讲新课** | 预习：让你看一遍、标不懂的地方，**带着问题去上课**；课上完回来，它还会回头对个账（"老师讲到了吗"） |
| **这块我总错** | 专门补这一块，练到会为止 |
| **下周考试** | 把考过的错题整理成一张清单，一条条过 |
| **考完了，拍卷子给它** | 看这次丢分在哪儿（按单元、按错法），错的收进账本，出一份"考后小结" |
| **这周怎么样** | 报告：他这周遇到了什么（**哪个对话里问都行，全科一起报**） |
| **背单词 / 记不住** | 换专门的方法来 |
| **练几道 / 来套卷子** | 出一套卷子一次给全（也可以"一道一道来"）；做完发它，它批"对几道错几道"、错的当场讲。卷子另附一页**家长版答案**，你收着核对用 |
| **放假了怎么学** | 排个假期计划 |
| **给我排张卷子** | 把到期的错题排成一张卷子，或把某个单元的知识点总结一遍 |
| **这题挺好，想留着** | **收藏**：原题抄一份放着（不排复习）；考试前还能从收藏里挑两道练手 |
| **帮我检查一下** | 一次报四样：今天到期几道、多久没摸底了、断更多久、错题账到没到报警线——末尾说一句**先做哪件事** |
| **下周要回顾几道** | 数给你听：一共几道、集中在哪几天——提前把时间排开 |
| **先记着，晚上讲**（拍完题说这句） | 存进「待讲」不现在讲；下次开场它自己会提起来 |
| **批一下**（拍一页作业） | 只给你错的那几道（"对几道错几道"），拿不准的请你核对；错的进错题本 |

**它自己判断该用哪个。** 你只管说事。

## 错题会一直攒着吗？不会

**每道错题进了账本，就会自己走流程：**

| 什么时候 | 会发生什么 |
|---|---|
| 当天 | 存进账本 |
| 1 天后 | 提醒孩子重做 |
| **独立做对 2 次** | **判定"真会了"，从账本上撤下来** |
| 一直做不对（错 3 次） | **不在这道题上纠缠了**——转成"知识点"，去补那个点 |

**所以最短 3 天就撤**（第 1 天对、第 3 天再对）；**错的次数多的，8 天左右也就不在那道题上纠缠了**，转成"知识点"去补那个点。**只有"每次都得提示才会"的会挂久一些**——那说明还没真会，该挂着。

健康的账本上只有 10-20 道活跃错题。

**另外它还会盯着两件事**：同一类题攒到 3 道就合并成"一个点"（不是三道题）；账上超过 40 道会主动提醒你——**那是报警线，说明哪里卡住了。**

**它还会提前提醒考试。** 中国学期节奏它知道（11 月期中、1 月期末、4 月期中、6 月底期末），会在**考前一个多月**主动问"你们定了什么时候考吗"，这样才来得及排复习。

## 三件你可能担心的事

**"我关了它，东西会不会没了？"**
不会。所有东西都存在你电脑上的 `孩子学习` 文件夹里，不在对话里。**对话是可以换的，一样都不会少。** **顺手做一件事**：隔段时间把整个 `孩子学习` 文件夹复制一份到 U 盘或网盘——电脑万一坏了，就靠它。

**"对话用久了变慢怎么办？"**
它会自己发现，然后主动提醒你开个新的。**不用你自己记。**

**"它会不会乱动我电脑里的东西？"**
不会。建项目的时候你只给了它 `孩子学习` 这一个文件夹。

│   └── 英语-2026秋.md
├── 收藏/
│   └── 数学/
│       ├── 数学.md      你说"这题挺好，想留着"的那几道（不排复习）
│       └── 图片/        那些题的原图

**这些文件夹不用你建**——第一次要写的时候它自己建。

**账本上只留"还没通的"**，通了的会自动挪进归档。所以你随时打开 `错题/` 看到的就是当前最要紧的那几道。

**这些不会上传到任何地方**——它自己不往外发一个字。（前面说的 U 盘 / 网盘备份是**你自己动手复制**的，不是它替你传的——那是你的选择。）想看看孩子的情况，直接打开文件看也行。

## 它会怎么对孩子

这几条是写死在"管家"里的，不管叫哪个老师来，都得守：

- **先看你卡在哪，再决定讲多少。** 你还能自己往下走，它会把几个选项摆出来让你点（"不知道这题在说什么""我会做，就是算错了"…）、最后一步留给你自己；你完全不会，它**直接讲**，不会追着问你。
- **一次只讲一小步**，讲完问"懂了吗"。说不懂就**换个说法重讲**，不重复原话。
- **不说"这很简单"。** 做错了不打击，做对了具体地夸。
- **几天没来不指责。** 它会说"有几天没来了，今天要不要少做一点"。
- **预习不讲透。** 讲透了孩子上课就不听了——只给几个问题，让他带着去上课。
- **大题不追求全对。** 从够得着的 (1)(2) 问开始做，做不到的那一问会**明确告诉孩子"你现在不用会"**，并说明理由——不会含糊过去，那会让他觉得"我太笨了"。
- **难的题不会直接扔掉。** 降到"看得懂"或"见过"这一档先放着，**记着什么时候回来再试一次**——等相关的知识点补上，再回来啃。

## 附：让 AI 帮你装（可选）

**已经装好了就不用看这一节。**

### 什么样的 AI 才能装

这套东西 = **技能** + **你电脑上的一个文件夹**（档案、错题本都在里面）。三样缺一不可：

1. **会读技能**——能自己判断什么时候该用哪一个；
2. **能读写你指定的那一个文件夹**；
3. **能看图**——孩子拍题是主入口。

**手机上的豆包、网页版的 ChatGPT / Gemini 都不行**：它们碰不到你电脑上的文件夹，
讲题可以、**存不了账**——这套东西在那边跑不起来。

### 怎么装：复制一句话给它

> 帮我装这个仓库里的技能：`https://github.com/shangyusheng/doubaojiajiao` —— 照仓库里的 `安装.md` 做，装到能用为止。

**打不开 GitHub 就找发这个包给你的人要压缩包**，内容一样，照第二步拖进去就行。

**接下来你只需要做它让你做的事。** 它能自己装就自己装完——连那段"每次都要遵守"的话都是它自己写进文件，不用你粘；
装不了（比如豆包工作），它会把"拖哪个文件夹、粘到哪个设置里"一步步说给你——你照做就行，不用记路径。

**豆包工作也能先试这一句**：它能不能打开链接，取决于你那一版有没有上网能力——打不开就照前面第二步手动拖，
不耽误（别在这上面反复试）。

**为什么它说的位置和下面这张表可能不一样**：各家界面会改版，以它在你这台机器上看到的为准。

### 那段"每次都要遵守"的话，填在哪

| 你用的 AI | 技能放哪 | 那段话填哪 |
|---|---|---|
| **豆包工作**（桌面·本地电脑） | 我的技能 → 上传技能 | 设置 → **工作任务偏好指令** |
| **Claude Code** | `~/.claude/skills/` 或项目里的 `.claude/skills/` | 项目根目录 `CLAUDE.md` |
| **ZCode** | `~/.agents/skills/` 或 `~/.zcode/skills/` | 项目根目录 `AGENTS.md` |
| **Cursor** | `~/.cursor/skills/` 或 `.cursor/skills/`（也认 `.agents/skills/`） | 项目根目录 `AGENTS.md`（或 `.cursor/rules/`） |
| **Codex** | `~/.codex/skills/` 或 `~/.agents/skills/` | 项目根目录 `AGENTS.md` |

**贴什么**：就是第三步 ③ 那一段，**一字不改**。有项目级的工具（后四个）就放进项目里——
它只在这个文件夹生效，比豆包那条"全局"干净得多。

### 装完先看一件事：东西存在哪

第一次建档后，去电脑上看一眼：档案是直接在你的文件夹里，还是多套了一层 `孩子学习`？
**两种都行，但以后每天必须是同一个地方**——档案分两处，账本就断了。

### 孩子自己用

**先只在豆包工作上开。** 豆包工作可以只授权一个文件夹；Claude Code、Cursor、Codex 这些
是能敲命令、能改电脑的编程工具——你自己用没问题，**别让孩子自己拿它用**：
孩子分不清"让它算一道题"和"让它动电脑"的边界。

（所以对外的说法是：**哪个 AI 都能装；孩子自己用，先在豆包工作上开。**）

### 想更新

对 AI 说：**"帮我看看技能是不是最新的"**。仓库里有个 `技能清单.md`，上面的日期就是版本。

> ⚠️ **装过 2026-10-22 之前那一版的，先看这条**：那时候"老师"那批是**英文名**
> （`agent-photo-question` 这种），现在改成了「老师·讲题」这样的中文名。
> **改名等于换了一个技能**——再传一遍不会覆盖旧的，会变成新旧两套都在里面，
> AI 可能挑到旧的那个。所以：**先把 `agent-` 开头的英文名技能全删掉，再装这一版。**
> 中文名那批（管家、科目）名字没变，但里面的内容也跟着改过了，
> **最省事的做法是全部删掉、整包重装一遍**——反正"装"就是拖一次文件夹。
