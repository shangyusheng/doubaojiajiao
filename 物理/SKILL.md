## 二、物理的错分四种

| 类别 | 孩子会怎么说 | 怎么补 |
|---|---|---|
| **概念没懂** | "概念记混了""不知道用哪个公式" | 回去讲概念 + **每个公式配一句"适用条件"** |
| **方法不会** | "知道要算，但不知道从哪下手" | 讲方法（受力分析 / 模型）+ 练同类 |
| **审题错** | "看漏了""理解错问什么了" | 练"框条件、框问题"（"光滑""恰好"这种词都是条件） |
| **计算错** | "我会做，就是算错了" | 练单位与规范（**不是"细心点"**） |

**物理最容易混的两个**：

- **"不会做"和"算错"是两回事** —— 让他**复述"这题问什么、用哪个模型"**，就知道是哪一种
- **"概念不懂"和"公式没记住"是两回事** —— 问"这个公式为什么成立、什么时候能用"，答不上就是概念问题

## 三、物理怎么讲

> **展开版在 `references\讲-方法与话术.md`**：讲一道题的完整流程（每一步问什么）、
> 具体招数（受力分析 / 电路 / 图像题）、初高中各自的坎、图怎么处理（画图动作 + 兜底句）。
> **这里有的，那里不重复。**

### 共同的三条（不分学段）

1. **先给他选项**（照第二节四类），别让他自己想说
2. **讲一小步就问"这一步懂了吗"**（懂了 / 有点糊 / 还是不懂）——**"有点糊"那一档必须留着**
3. **说"不懂"就换个说法**（不许重复原话）；**最后一步（算出结果）留给他**

### 物理讲一道题的骨架：现象 → 条件 → 模型 → 定量

1. **说现象**：先让他一句话说清"发生了什么"（谁在动、从哪到哪、状态怎么变）——**先别替他描述**
2. **找条件**：把题里每个词翻译成物理含义（"光滑"= 不算摩擦；"匀速"= 合力为零）
3. **定模型**：这是哪一类？（斜面 / 杠杆 / 电路 / 浮力…）——**模型选对，公式才有用**
4. **定量**：先列已知（量 = 数 + 单位）→ 选公式（**先问适用条件**）→ 算 → 三查（单位 / 大小 / 方向）

**"换个说法"往哪换**（他卡住就一条条试；括号里是例子）：

| 招 | 怎么用 |
|---|---|
| **换表征** | 文字 ↔ 图（受力图 / 电路图）↔ 公式——说不清就画，画不出就算 |
| **换情境** | 电路 ↔ 水流；杠杆 ↔ 跷跷板；（拿生活里见过的类比） |
| **换模型** | 太难的样子，先换成见过的同类模型上手 |
| **拆过程** | 多过程拆成"一过程一问" |

> **能说出来才算真会**：讲完让他**用自己的话说一遍**（现象 → 条件 → 用哪个公式）。
> 说不清的地方就是没懂的地方——比再讲一遍有用。

### 初中：三个坎

- **坎①公式**：第一次"用公式算物理"——先估算常识（"这个数大概该多大？"），再动笔
- **坎②画图**：力的示意图、光路图、电路图——**图就是物理的草稿纸**，不会画就理不清
- **坎③电学**：电流看不见——用水流类比 + 动手画等效电路

### 高中：先定模块，规范就是分

- **先定模块**：力与运动 / 机械能 / 电场 / 电路 / 磁场 / 电磁感应——判断在哪个模块，再调思路
- **两大基本功**：**受力分析 + 运动过程分析**——所有力学题都是这两件事的组合
- **规范就是分**：画受力图 / 过程图、写原始公式（不写变形结果式）、分步列式（不写连等式）、方程编号、结果带单位

## 四、物理怎么练

> **展开版在 `references\练-方法与配比.md`**：闭环几个动作展开说、初中和高中各自多出来的一条、
> 没图怎么练。**这里有的，那里不重复。**

### 共同（不分学段）

- 讲完一道题 → 同类**变式 1-2 道**（**换数字、换情境、换问法**，**不是原题**）
- **同类错点 → 隔天同模型复测**（错题对应模型写成一张卡，下次换情境再测）
- 反馈**必须标错因**，不能只说对错（例：不说"错了"，说"错在**模型**——把匀速当成了加速"）
- **一题一模型、一次只练一个小目标**

#### 难度：三档，配比按孩子调

| 档 | 是什么 | 干嘛用 |
|---|---|---|
| **基础** | 他会的 | 热身、稳住基本分 |
| **巩固** | **刚好不会那条线** | **出题主力**——找的就是这条线 |
| **拔高** | 够一够能到的 | 往上顶 |

配比默认 **40% / 40% / 20%**（中等水平）：基础薄弱 → 基础多、**拔高几乎没有**；好学生 → 巩固拔高多、基础只热身。

**拔高的方向**：同一个考点往深走——**加过程**（单过程 → 多过程衔接）、**加耦合**（换模型组合）、**加问**（从"算一个量"到"讨论 / 验算"）。

> **不往上学段。** 初中的孩子给高考题——他缺的是**工具**，不是智力，只会看不懂而挫败。

> ⚠️ **别把三个"档"混起来——名字像，管的事完全不同**（难度三档就是这一节；
> 五档降级和三档判定在「复习账本」第九节、第二节）。

### 初中

- **概念判断**（生活情景说物理量）+ **画图专项** + **单位换算专项**（km/h ↔ m/s、g/cm³ ↔ kg/m³）+ **实验题说步骤**

### 高中

- **模型专项**（一个模型一组打）+ **过程拆分画图** + **限时练** + **规范书写**（原型公式 + 编号）

## 五、物理怎么诊断（摸底和考试看什么）

> **展开版在 `references\诊断-错因与诊断卡.md`**：四类错因在物理里的具体表现、
> **14 张诊断卡**（初中 7 / 高中 7，按知识点查：常见错法 → 卡点 → 补救讲法 → 变式提问）、
> 各学段知识树骨架、**超纲红线**。

| 学段 | 看什么 |
|---|---|
| **初中** | 概念判断准不准、图画不画、单位换不换、实验步骤说不说得清 |
| **高中** | 模型判断、受力 / 过程分析、图像读不读得懂、规范丢不丢分 |

**反馈时多看两点**（**不算新的错因类别**——记账、给孩子认，永远只有四类）：
**图有没有画**（受力图 / 过程图画对，题就成了一半）和**公式的适用条件说得出吗**。

**孩子拿来一道题、或者一道题反复错** → 翻 references 里的诊断卡，对号入座。

**摸底的做法见「摸底」**：一科 6-8 题、**一次只给一道**、从"这一年的中等难度"起步、对加难错降。
