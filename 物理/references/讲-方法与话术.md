## 一、讲一道题的完整流程

**四步不是走完，是"他卡在哪一步，就在那一步多待一会儿"。**

### 第一步 · 说现象（发生了什么）

先让他用一句话把过程说清——这一步同时是在看他卡在哪：

- 「这道题里发生了什么？谁在动、从哪到哪、状态怎么变？」
- 多过程让他**按顺序分**：「先……然后……最后……」
  （例：小球从斜面滚下 → 撞上弹簧 → 被弹回）
- **先别替他描述。** 说不清现象，后面全白搭。

### 第二步 · 找条件（哪些词是条件）

每个词都翻译成物理含义：

- 「题里有没有'光滑''匀速''静止''恰好''正常发光'这种词？它们各说了什么？」
  （例：光滑 = 不算摩擦；匀速 = 合力为零；恰好 = 临界状态）
- 「题目给了哪些量？要求哪个量？」——**框出来**，别算着算着忘了求什么。

### 第三步 · 定模型（这是哪一类）

**模型选对，公式才有用：**

- 「这题像课本里哪一类？（斜面 / 杠杆 / 电路 / 浮力 / 碰撞……）」
- 「要求的是哪个物理量？它归哪个模型管？」
- **一题一模型**：讲完把这道题"存"进对应模型的卡片，下次换情境再用。

### 第四步 · 定量（列式算）

- 「先把已知写成'量 = 数 + 单位'排一排」——**单位不统一先换算**
- 「用哪个公式？**它的适用条件对得上吗**？」——公式条件不清是最常见的陷阱
- 算完**三查**：单位对吗 / 大小说得通吗 / 方向和正负号对吗

> **最后一步（算出结果）留给他**——这是 `SKILL.md` 第三节共同三条里的那条。

## 二、具体招数（一条一行）

### 受力分析（物理第一基本功）

- 口诀：**一重二弹三摩擦（四其他）**——先画重力（永远竖直向下）→ 再弹力（接触 + 形变才有）
  → 再摩擦力（粗糙 + 有压力 + 有相对运动或趋势）→ 电场力 / 磁场力等其他力
- 铁律：**每个力都要找到"施力物体"，找不到 = 不存在**
  （惯性不是力；"下滑力""冲力"找不到施力物体，不画）
- 只画**性质力**（重力 / 弹力 / 摩擦力），不画**效果力**（向心力 / 回复力）
- 判断有无用**假设法**：假设接触面光滑，物体还能保持原状吗？（不能 → 有摩擦力）
- 顺序：**先整体、后隔离**；研究对象一次一个（"隔离谁"要说出口）

### 电路分析（初中电学）

- 简化两招：**电压表当断开、电流表当导线** → 数电流路径定串并联（一路上不分流 = 串联）
- 欧姆定律"三性"：**同一导体**（I、U、R 对同一段电路）、**同一状态**（滑片一动，全组数据换新）、**单位统一**
- 动态电路：先找**不变量**（电源电压、定值电阻），再看变量引起的连锁变化

### 图像题

**"六看"**：看轴（谁随谁变）→ 看线（形状）→ 看斜率 → 看面积 → 看截距 → 看特殊点（交点）。

- 两条最容易错的：**图线不是轨迹**；**交点 ≠ 相遇**（v-t 图交点 = 速度相同）

### 公式表

每个公式配一句"**适用条件**"——做题先问条件对不对（题目常出在"条件不符"上）。

### 单位与规范

已知量**先统一单位再算**；结果带单位；物理量符号和单位符号别混用。

### 实验题四问

**测什么 → 用什么器材怎么测 → 证据是什么 → 结论怎么来。**

## 三、初中：三个坎怎么过

### 坎①：第一次"用公式算物理"

从生活经验到定量计算。做法：**先估算常识**（"这个数大概该多大？"），再动笔。

### 坎②：画图刚起步

力的示意图、光路图、电路图——**图就是物理的草稿纸**。画的规范比画的漂亮重要。

### 坎③：电学"看不见"

电流摸不着。做法：**水流类比** + 动手画等效电路（简化两招，见上面「电路分析」那条）。

### 单位换算是初中重灾区

km/h ↔ m/s（÷3.6）、g/cm³ ↔ kg/m³（×1000）——**单独练**。

### 概念判断先用生活例子

惯性、压强、蒸发……先"生活话 ↔ 物理话"来回翻，再回题目。

## 四、高中：先定模块，规范就是分

### 先定模块

力与运动（牛顿定律）/ 机械能 / 电场 / 电路 / 磁场 / 电磁感应——
判断在哪个模块，再调对应思路。

### 两大基本功

**受力分析 + 运动过程分析**——所有力学题都是这两件事的组合。
多过程题：按时间标 A→B→C、画过程图、**抓衔接点**（上一过程末速度 = 下一过程初速度）。

### 规范就是分（高中开始按步骤给分）

- 必要的**文字说明**：研究对象、所设字母含义、正方向、方程依据——
  按"**五个 W**"过（对谁 / 哪段 / 凭哪条定律 / 为什么 / 答什么）
- **写原型公式，不写变形结果式**（例：写 `qvB=mv²/R`，不直接写 `R=mv/qB`）
- **分步列式、不写连等式**（一处错不全错）；方程**编号**①②③
- 字母运算到最后再代数据；结果带单位、矢量说明方向

## 五、图怎么处理（画图动作 + 兜底句）

> 孩子那边**只有**他打的字、家长转述、拍来的照片。
> 物理和地理不同：**它的图大多不用找、是画出来的**——这反而是优势。

- **首选动作**：「你先在纸上画个受力图（/ 电路图 / 过程图）——画完拍给我；或者你说着画、我来问。」
- **带图的题**（图像题、装置图）：用他卷子上那张（拍来）；看不清就"你说图上有什么 / 横轴纵轴各自是什么"
- **红线**：**不许说"我给你找了张图"**；不许描述一张没见过、没拍来的图
