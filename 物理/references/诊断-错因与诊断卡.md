## 一、四类错因，在物理里长什么样

> 「复习账本」第八节给的是四类的机制，这里只说**物理里的具体表现**。

- **概念没懂** —— "概念记混了 / 不知道用哪个公式"。物理的概念断层。
  （例：重力 / 压力不分；惯性和力混；公式条件不清——拿"只在纯电阻里成立的关系"到处用）
  **补法 = 回去讲概念 + 每个公式配一句"适用条件"。**
- **方法不会** —— "知道要算，但不知道从哪下手"。模型选错、图像读错、**受力分析漏力**、过程拆不开。
  （例：见"多过程"不拆段；v-t 图像只看形状不看轴）
  **补法 = 讲方法（见「讲-方法与话术」第二节）+ 练同类模型。**
- **审题错** —— "看漏了 / 理解错问什么了"。物理特有的几种：
  漏条件（"光滑""恰好"没看见）、看错要问的量、单位不统一就开始算。
  **补法 = 练"框条件、框问题"。**
- **计算错** —— "我会做，就是算错了"。物理特有的几种：
  **单位问题**（没换算、结果不带单位）、正负号和方向、运算失误。
  **补法 = 单位与规范专项**（见「练-方法与配比」第二、三节），**不是"细心点"。**

> 这里面最容易混的两对——"不会做"和"算错"、"概念不懂"和"公式没记住"——
> **判法在 `SKILL.md` 第二节**，这里不重复。

## 二、诊断卡（按知识点查）

> 每张卡：**常见错法 → 背后卡点 → 补救讲法 → 变式提问**。
> 用法：孩子拿来的题对上了哪张，就按它的"补救讲法"走，再用"变式提问"验他是不是真懂了。
> 一道题**反复错**的时候也翻这里——多半能对上某一张。

### 初中

**力的示意图：漏力 / 多力**
- 常见错法：少画摩擦力；把"惯性""下滑力"画成力
- 背后卡点：没有"找施力物体"的习惯
- 补救讲法：按**一重二弹三摩擦**顺序走一遍，每画一个力问一句"**这个力是谁给的**"——找不到施力物体的划掉
- 变式提问："这个力是谁施加的？"→ 换成"假设接触面光滑，这个力还在吗？"

**单位换算**
- 常见错法：速度题 km/h 直接代；密度题 g/cm³ 和 kg/m³ 混着算
- 背后卡点：不知道"单位必须统一才能算"
- 补救讲法：动笔前先做一件事——**已知量全部换算成一套单位**（速度统一 m/s、密度统一 kg/m³）再列式
- 变式提问："36 km/h 是多少 m/s？"→ 换成"2.7 g/cm³ 是多少 kg/m³？"

**串并联判断错 / 欧姆定律乱套**
- 常见错法：看着像并联就当并联；同一题里 I、U、R 不来自同一段
- 背后卡点：不会简化电路；没有"同一导体、同一状态"的意识
- 补救讲法：简化两招（**电压表当断开、电流表当导线**）→ 数电流路径定串并联；
  用欧姆定律前先说"这三样是同一段电路的"
- 变式提问："电流从正极出发走哪条路？"→ 换成"去掉一个灯，另一个还亮吗？"（断开法判并联）

**光路图：角度基准错**
- 常见错法：反射角按"光线与镜面的夹角"量（应是相对**法线**）
- 背后卡点：角度的基准线不明确
- 补救讲法：固化一步——**先画法线（垂直镜面），再量角**；反射角 = 入射角，两边对称
- 变式提问："入射角 30°，反射角多少？"→ 换成"光从空气斜射入水里，折射角比入射角大还是小？"

**浮力：两套工具分不清**
- 常见错法：见"浮力"就套 F=ρ液gV排（不管物体漂浮）
- 背后卡点：没有"先判断状态、再选工具"的意识
- 补救讲法：**先判状态**——漂浮 / 悬浮 → 先用 F浮 = G；沉底 / 求浮力本身 → 阿基米德 F=ρ液gV排；
  两套都摆出来让他选
- 变式提问："木块漂着，它受的浮力是多少？"→ 换成"同一个物体在水和盐水里，浮力一样吗？"

**密度计算：单位与体积**
- 常见错法：g 和 cm³ 不配套直接除；空心球问题体积用错
- 背后卡点：单位意识 + 题意读不全
- 补救讲法：先统一单位（g 配 cm³、kg 配 m³）再除；实心空心题先问"它体积指的是哪部分"
- 变式提问："500 g、200 cm³ 的密度是多少？"→ 换成"空心球的平均密度怎么算？"

**实验题：结论不写前提（控制变量）**
- 常见错法：写出"电阻越大电流越小"，没写"电压一定时"
- 背后卡点：控制变量意识弱
- 补救讲法：结论套句式——"**在……一定时，……越……，……越……**"；说结论前先回答"我控制了哪些量"
- 变式提问："你这句结论的前提是什么？"→ 换成"这个实验里谁是变量、谁被控制？"

### 高中

**受力分析：漏摩擦力 / 方向判反**
- 常见错法：忘记摩擦力；摩擦力方向画成"运动方向"
- 背后卡点：没有"先判有无、再判方向"的步骤
- 补救讲法：有无用**假设法**（假设光滑看状态变不变）；
  方向看"**相对运动 / 相对趋势的反方向**"（不是"运动方向"）；
  斜面上"静止 / 匀速 / 加速"三种情况对比一遍
- 变式提问："假设这里光滑，物体会怎样？"→ 换成"摩擦力是帮它还是拦它？"

**多过程题目：不拆过程**
- 常见错法：全程套一个公式；衔接点条件丢掉
- 背后卡点：没有"按时间顺序分过程"的习惯
- 补救讲法：按时间标 **A→B→C**、画过程图、一个过程一套受力 + 一套规律；
  **抓衔接点**（上一过程末速度 = 下一过程初速度）
- 变式提问："这题分几段？分界点是什么？"→ 换成"上一段的末速度去哪了？"

**牛顿第二定律：方向对应错**
- 常见错法：a 和力不对应；合力的方向搞错
- 背后卡点：没有"先明确对谁、沿哪个方向"的习惯
- 补救讲法：列式前先说两句——"对哪个物体""沿哪个方向"；再写 F合 = ma；正方向先规定
- 变式提问："它此刻的加速度朝哪？"→ 换成"合力方向和速度方向一定一致吗？"

**机械能守恒：没验条件就套**
- 常见错法：有摩擦也套守恒；"守恒"和"动能定理"混用
- 背后卡点：不检查"只有重力 / 弹力做功"
- 补救讲法：套之前三问——有摩擦吗？有其他力做功吗？；条件不满足就换动能定理
- 变式提问："这题能守恒吗？凭什么？"→ 换成"同一道题加上摩擦，怎么解？"

**电、磁：方向判断（左右手）**
- 常见错法：左手右手混用
- 背后卡点：三个定则各管什么没分清
- 补救讲法："**左力右电**"——左手定则判**力**（安培力 / 洛伦兹力）；右手定则（及安培定则）判**磁场 / 感应电流**；
  每个定则配一个半个手掌比划一遍
- 变式提问："给电流和磁场，求力的方向用哪只手？"→ 换成"给导体切割磁感线，判断电流方向用哪只手？"

**图像题：物理意义读错**
- 常见错法：把 v-t 图的"交点"当"相遇"；把图线当轨迹
- 背后卡点：只记形状不记"轴和面积"的含义
- 补救讲法："六看"过一遍（轴 → 线 → 斜率 → 面积 → 截距 → 特殊点）；
  两条铁律——**图线不是轨迹、交点按图种解释**
- 变式提问："这段面积代表什么？"→ 换成"两条线交点什么意思？一样吗？"

**规范丢分**
- 常见错法：不画受力图 / 过程图；写连等式；结果不带单位
- 背后卡点：不知道"步骤就是得分点"
- 补救讲法：得分点清单自查——画图了吗 / 原型公式写了吗 / 分步列式编号了吗 / 结果带单位了吗；
  拿他写的一步一步对清单
- 变式提问："你这条答案哪里能得分？"→ 换成"这道题换你当阅卷老师，给几分？"

## 三、知识树骨架（板块级，用于诊断定位；不是单元清单）

> 要精确到单元，得查教材（人教版）。

- **初中**（人教版：**八年级开始开课**）：
  八上（机械运动 / 声现象 / 物态变化 / 光现象 / 透镜 / 质量与密度）→
  八下（力 / 运动和力 / 压强 / 浮力 / 功和机械能 / 简单机械）→
  九年级（内能 / 内能的利用 / 电流和电路 / 电压电阻 / 欧姆定律 / 电功率 / 电与磁 / 信息的传递 / 能源）。
  2022 版课标按五个一级主题（**物质 / 运动和相互作用 / 能量 / 实验探究 / 跨学科实践**）组织，另有 **21 个必做实验**。
- **高中**：必修1（运动描述 / 相互作用 / 牛顿运动定律）→ 必修2（曲线运动 / 万有引力 / 机械能）→
  必修3（静电场 / 电路 / 电磁场初步）→ 选必1（动量 / 机械振动与波 / 光）→
  选必2（安培力与洛伦兹力 / 电磁感应 / 交变电流 / 传感器）→
  选必3（分子动理论 / 气体 / 热力学定律 / 原子与波粒二象性 / 原子核）。
- **四素养是同一套、不分学段**：初高中都是物理观念 / 科学思维 / 科学探究 / 科学态度与责任——
  **区别在内容的深度和数学工具**，诊断时别把"高中才要求的定量推导"当成初中该会的。

## 四、超纲红线（收材料、出题之前过一遍）

- 边界口径：初中按义务教育物理课程标准（五个一级主题）；高中按必修 / 选择性必修。
- 辅导班 / 竞赛材料常"提前教"——**收进来之前过一遍学段边界**；拿不准的先别用。
- 已知的常见提前教（示例，**逐条以课标为准**）：
  - **牛顿第二定律（F=ma 定量计算）** → 高中；初中只到"力的示意图 + 二力平衡"定性
  - **矢量分解 / 合成定量运算** → 高中；初中力只作示意图
  - **动能定理、动量** → 高中；初中只到"功、功率、机械效率"的计算
  - **加速度概念** → 高中；初中只描述"快慢、变化"，不引入 a
