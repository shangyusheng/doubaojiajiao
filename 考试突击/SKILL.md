# 考试突击

**核心逻辑只有一句话：时间不够的时候，帮你决定先做什么、放弃什么。**

---

## 一、先问四个数

必须知道：

1. **考什么**（哪几科、哪几个单元）
2. **什么时候考**（还剩几天）
3. **现在什么水平**（从「复习账本」和学科文件读，**不要问家长**）
4. **每天能花多少时间**

**缺了不要一次问完**——只问最关键的那一个。

**问的时候都给选项，别让她自己想说**：

> - 考哪几科？（**从 `档案.md` 的「学的科目」里读，只列她录过的**，末了加一个“○ 还有别的”）
> - 单元是哪些？（**把学科文件里这本书的单元列出来让她勾**——和「摸底」第一步同一个做法）
> - 什么时候考？○ 这周　○ 下周　○ 下下周　○ 还没定
> - 每天能挤多少时间？○ 20 分钟　○ 半小时　○ 一小时以上

> **选项从哪来**：科目和单元都从 `档案.md` 和 `学科/<科目>.md` 的「这本书」里读，**不要写死、不要让她背**。
> 她可能只记得“快考了”，说不出单元名——**列表一摆，她一眼就认出来**。

> 「每天学习」会在考**前 4-6 周**主动提醒家长问这件事。如果家长自己来说，说明还没问过，那就问。

---

## 二、六步流程

1. **诊断** —— 找出**最值得先提分的模块**，给 1-3 个最优先提分点（不是"哪里都不会"，是"哪里补了最有用"）
2. **取舍** —— **区分保分项、突破项和放弃/降权项** ← 这一步最值钱
3. **排路径** —— 按优先级排复习节奏
4. **排任务** —— 每个任务都要标注**时长、题量、难度、完成标准**
5. **错题转卡** —— 每道错题转成：错因卡片 + 同类追练 + 下次复测时间
6. **收尾** —— 输出**今天立刻能做的第一步**，并说明"下次反馈什么数据"

**三档取舍的意思**：

| 档 | 是什么 | 怎么办 |
|---|---|---|
| **保分项** | 他基本会，只是不熟 | **优先**——投入少回报高 |
| **突破项** | 有洞，但剩下的时间够补 | 排进去 |
| **放弃/降权项** | 洞太深，时间补不上 | **明确说放弃**，别让它占时间 |

**放弃的话要说出口**，别含糊过去。

## 三、按科目换诊断（唯一的真差异）

| 科目 | 诊断先看什么 |
|---|---|
| **语文** | 阅读失分点、作文问题、基础题稳定性 |
| **数学** | 基础题丢分、方法不会、模型选错、时间分配 |
| **英语** | 词汇缺口、阅读错因、听力定位、写作表达 |
| **物理** | 概念不清、模型不会建、图像读错、计算表达 |
| **化学** | 方程式、实验现象、推断路径、计算步骤 |
| **生物** | 概念混淆、图表阅读、实验变量、表达准确性 |
| **历史** | 时间顺序、史实记忆、材料提取、因果解释 |
| **地理** | 地图定位、图表信息提取、区域特征记忆、成因解释 |
| **政治** | 概念混淆、材料关键词遗漏、观点不贴题、表达层次 |

**诊断按科目换，错因不换——错因只有四类，全科通用**（见「复习账本」第八节）：
概念没懂 / 方法不会 / 审题错，加上按科目选的计算错（理科）或表达不完整（文科）。
科目特有的说法写在四类后面的**具体描述**里，写法见「教材同步」第二节。

---

## 四、按学段换策略

| 学段 | 特点 |
|---|---|
| **小学** | 范围小。重点在**基础题不丢分 + 错题不再错**，**不要搞题海** |
| **初中** | 中考是第一次带区分度的考试。按科目权重排，先保语数英 |
| **高中** | 总复习。**按性价比排，不按难度排**——从"补了能涨分"的地方下手 |

## 五、和别的技能怎么配合

**和「每天学习」第四节的分工**：
- 小考（下周单元测试、月考）→ 「每天学习」第四节 + `agent-review-assistant`（轻量级：列清单 + 用“问”不用“看”）
- 大考（期中/期末/中考/高考）→ **走这里**（完整战略：诊断 → 取舍 → 排路径 → 保分/突破/放弃三档）
- 考完了收错题 + 出"考后小结" → 就在本技能末尾（**考后**那段：拍卷子 → 收账 → 归因 → 小结）

**先做的三件事**（别一上来就讲题）：

1. **捞清单** —— 从「复习账本」里把"考的这几个单元内**所有错过的知识点**"捞出来，一条不漏，按单元分组，每条一句话，**只写"该注意什么"，不写题目不写答案**（规矩见「每天学习」第四节）
2. **订正方式用"问"不用"看"** —— 重看会制造"我懂了"的错觉
3. **清单单独存一份**（`.md`），考试当天早上还能扫一眼

**存哪里**：`孩子学习/考前/<科目>-<考试名>.md`（例：`考前/数学-2026秋期末.md`）。**`考前/` 文件夹不在就自己建，不问家长。**

**过程中**：

- **考前一周：不做新题**，集中过错题本——重点看反复错的那几道和难题、易错陷阱；**顺带问一句"要不要从收藏里挑两道"**（收藏里都是见过的旧题）
- 讲题 → `agent-photo-question`
- 专项补 → `agent-weakness-boost`
- 过错题 → `agent-mistake-review`
- 想按课本补 → 「教材同步」

**考后（考完当天或第二天做，别拖）**：

1. **拍卷子来**：让家长把**卷子 + 他写的答案（或答题卡）**拍照发来——**一张一张拍、拍清楚**。识别完**先请家长核对一遍**（"第 4 题是错的对吧？"）——读照片有看走眼的时候，**不冒充权威**。
2. **错的逐题收账**：每道错题照「复习账本」写全（题面 / 考什么 / 错因四类……）——**考试是错题最大的来源，不收就白考了**。
3. **归因别开放问，给选项**（和「每天学习」第四节同款）：

   > 这次的分主要丢在哪几种？（可多选）
   > - ○ 时间不够，后面没做完
   > - ○ 有几道题完全没见过
   > - ○ 看错了 / 算错了，本来会做
   > - ○ 有一整块（单元）都不会
   > - ○ **说不清** —— 那我们一张一张看卷子

4. **出一份"考后小结"**（对话里给）：按单元把丢分聚在一起——**哪块稳、哪块漏**；和考前清单对个账（"考前重点看的 3 个点，有 2 个真考了"）；最后给一句下一步（**先补哪两个洞**）。
5. **记一笔**：照「每天学习」第六节，把这场考试写进 `记录/`——"做 N 道（对 X、错 Y）；错在：……×n"——**不记，统计页和月度记录就把考试这天漏掉**。

> **拍不了 / 读不了图时**：退回"报错题号 + 家长转述哪块难"——流程照走，别卡在拍照上。

## 六、红线

- **不承诺押题命中**
- **难度要匹配**——小学生尤其别给太多题
- 每个任务都要能直接执行，不只给"你要多练习"这种空话

---

> **红线（被直接叫到也要守）**：照片／错题／对话不外传、不说技术词——其余的线见「每天学习」第五节。
